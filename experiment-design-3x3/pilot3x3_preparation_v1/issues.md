## 🔴 阻塞项（Blocking）

### I-001：模型梯度未验证
- **状态**：BLOCKED
- **描述**：A1(qwen3.8-flash) / A2(qwen3.7-max) / A3(qwen3.8-max) 的能力梯度尚未通过独立校准集验证
- **风险**：如果梯度不成立，整个 Model 自变量的解释就有问题
- **解决方案**：运行 20 题校准集 × 3 模型 × K1 条件，验证 A3 > A2 > A1
- **备选方案**：如果 A2 位置不稳定，改称 "three models with empirically differentiated baseline capability"

### I-002：EP 标签双盲审核未完成
- **状态**：BLOCKED
- **描述**：目前只有一位审核人的 EP 标签，缺少第二审核人，无法计算 Cohen's κ
- **目标**：κ ≥ 0.80
- **解决方案**：安排第二审核人独立标注，计算一致性

### I-003：K2/K3 Evidence Schema 未实际对齐
- **状态**：BLOCKED
- **描述**：规范已写好，但 K2 搜索结果和 K3 领域 RAG 结果尚未实际转换为统一格式
- **风险**：格式差异可能成为混淆变量
- **解决方案**：实际运行 16 题的 K2/K3 检索，统一转换为 Evidence 1-5 格式

### I-004：知识操纵检查未完成
- **状态**：BLOCKED
- **描述**：E1 题的 answer-bearing recall、authoritative-source rate 等指标尚未评价
- **重要性**：这是解释 K2/K3 效果差异的关键机制变量
- **解决方案**：K2/K3 检索结果出来后，人工标注每项指标

## 🟡 重要风险项（High Priority）

### I-005：标签不平衡 - E0P0 和 E1P0 全是 CORRECT
- **状态**：WARN
- **描述**：
  - E0P0：4 题全 CORRECT（0 INCORRECT）
  - E1P0：4 题全 CORRECT（0 INCORRECT）
  - 总体：12 CORRECT / 4 INCORRECT（3:1，不是 1:1）
- **风险**：
  - Ceiling effect：如果模型在这些题上正确率已经很高，RAG 增益的检测效力会下降
  - 假阳性/假阴性分析不平衡
- **解决方案**：
  - Pilot 先跑，看实际正确率分布和 ceiling/floor 情况
  - 正式实验扩充时，有意识地增加 INCORRECT 题
  - 目标：总体接近 1:1，每类 EP 内部尽量 2:2 或 3:2

### I-006：E0P0 题目类型单一
- **状态**：WARN
- **描述**：4 道 E0P0 题全是"环保投资占比"同类型题目
- **风险**：类型多样性不足，结果推广性有限
- **解决方案**：正式实验扩充时增加不同类型的 E0P0 题（如字段提取、数据查找等）

### I-007：A2 是上一代旗舰，代际混杂
- **状态**：WARN
- **描述**：A2 选 qwen3.7-max（上一代旗舰），与 A1/A3（同代 3.8 系列）不在同一代际
- **风险**：代际差异可能引入训练数据、post-training 策略等混淆因素
- **解决方案**：
  - 操纵检查验证梯度是否成立
  - 如果成立，论文中如实说明模型选择理由
  - 讨论局限性时承认代际混杂

### I-008：上下文长度混淆变量
- **状态**：WARN
- **描述**：K1/K2/K3 的输入长度明显不同（K1 最短，K2/K3 更长）
- **风险**：效果差异可能部分来自上下文长度而非知识内容
- **解决方案**：
  - 记录 input tokens
  - 控制 K2/K3 的 evidence token budget 尽量接近
  - 敏感性分析中纳入 input tokens 作为协变量
  - 不增加 R0 空文本组（会引入注意力干扰）

### I-009：Pilot 16 题统计效力不足
- **状态**：WARN
- **描述**：16 题对三维交互检验效力严重不足
- **注意**：Pilot 的定位是方法学验证，不是假设检验
- **解决方案**：
  - Pilot 只回答操纵有效性和可行性问题
  - Pilot 后做 simulation-based power analysis
  - 根据效力分析决定正式实验题量（40/60/80）

## 📋 研究诚信边界提醒

### 可以修的
- 实验操纵是否有效
- 资产是否公平
- 变量定义是否清楚
- 样本量是否足够

### 不能修的
- 结果方向
- Gold 答案（为了得到"好看"的结果而换题/改答案）
- 评分规则（运行后改规则以迎合结果）
- 假设方向（看到结果后改 H 的方向）
