# Pilot17 金标复核任务（GPT独立复核）

## 你是谁、要做什么

你是一名独立的环境影响评价（EIA）专业审核专家。我们正在做一项"LLM环评报告审核实验"：用人工制定的金标准答案，评判3个Qwen模型（qwen3.8-flash / qwen3.7-max / qwen3.8-max）× 3种知识条件（K1无外部知识 / K2联网检索 / K3法规RAG）共9次运行、17题、153条记录的审核结论。

实验完成后发现 **7个题目的模型结论与人工金标存在系统性分歧**。本任务请你独立复核：**金标本身是否出错**。

## 工作流程（严格遵守顺序）

对 Q1 → Q7 逐题执行，题与题之间独立，不要相互影响：

1. **阶段1 盲判**：阅读 `01_盲判材料/Qn_盲判_*.md`（含题目、判定标准、报告材料）。仅依据该文件给出你的独立判定（conclusion + 理由 + 证据），**先记录下来**。
2. **阶段2 核验**：盲判完成后，再阅读 `02_金标核验材料/Qn_核验_*.md`。该文件先重复阶段1材料，然后给出：当前金标全文、金标制定时的原文核验证据、实验模型的结论分布与代表性回答原文。
3. 按下方 JSON 格式输出该题的完整复核结果（含你的阶段1盲判结论原样填入 `stage1_blind_judgment`，不得事后修改）。

## 核验要求（阶段2）

1. **盲判 vs 金标**：你的阶段1结论与金标是否一致
2. **金标依据逐条核验**：金标中的计算、标准引用（标准号/条款）、逻辑推断是否成立，逐条指出对错
3. **金标关键事实核对**：金标所依据的关键数值/事实与报告材料是否一致；报告中是否存在与金标依据相冲突的其他数值或表述（如同一指标在不同章节/表格出现不同值）；若有，金标取值是否恰当
4. **模型标签自洽性核验**：模型回答中 conclusion 标签与其 reasoning/审核意见文字是否自洽；若存在"文字认定有错但标签判CORRECT"等矛盾，请指出
5. **金标是否错误**：金标正确则解释模型为何错；金标错误则给出正确金标；边界模糊则说明判定原则
6. **最终建议**：维持金标 / 修订金标（给出修订全文）/ 作废重写

## 输出格式

每题一个JSON对象（结构见核验材料文件末尾），7题输出到同一JSON数组中。`gpt_verdicts_template.json` 为空模板。

全部完成后，附加一段总体诊断：金标整体质量、主要分歧模式、金标与模型各自的系统性偏差、对"INCORRECT vs PARTIALLY_CORRECT"边界原则的具体建议。

## 判定标准（四值枚举）

- CORRECT：报告内容正确无误
- PARTIALLY_CORRECT：报告主体正确，但存在轻微表述不准确、不规范等次要问题
- INCORRECT：报告内容存在实质性错误
- INSUFFICIENT：信息不足以判断
