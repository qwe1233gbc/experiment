## 使用说明

每个问题类型文件夹同时保留两种口径：

1. `01_核心答案依据文件`用于说明该类问题原则上依赖哪些知识文件；
2. `02_实验Top5实际检索文件`用于复核正式实验中模型实际看到了哪些RAG来源。

两者可能不同：核心依据是人工冻结的预期证据，Top-5是检索算法实际召回结果。论文分析时不得把“被检索命中”直接等同于“构成最终结论的有效证据”。
