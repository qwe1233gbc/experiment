# Codex 最小交接模板

```markdown
# 任务
一句话说明需要 Codex 完成或判断的事项。

# 已确认事实
- 只列已经由权威文件确认的事实。
- 每项附来源路径；必要时附 hash、版本或状态。

# 相关文件路径
- 只列完成当前任务必需的文件。
- 不提交整个项目目录。

# 关键代码或参数片段
- 仅摘录目标函数、相关字段或必要行。
- 大文件使用行号、sheet、JSON key 或函数名定位。

# 冲突点
- 候选值及各自来源。
- 无法解决时明确写 UNRESOLVED。

# 需要 Codex 判断的问题
1. 明确列出需要科研、设计或复杂代码判断的问题。

# 权限边界
- 允许的修改范围：
- 禁止修改的正式产物：
- 需要返回的验证证据：
```

生成后先检查：是否包含无关全文、历史版本、大量输出或可由 DSH 直接完成的工作。默认先向用户展示并等待确认，再调用 Codex。
