# 实验方案：模型能力 × 知识来源对环评报告审核质量的影响
## —— 一项 3×3 析因实验设计

> 研究方向：智慧环评 · 大语言模型 · 检索增强生成
> 版本：v4.0 · 2026-08-31
> 核心主题：**环评法规密集型场景中 RAG 的增益边界与知识替代效应**

---

## 1 研究背景与科学问题

### 1.1 现实背景与应用趋势

环评报告审核是一项法规密集型专业任务。审核人员需同时掌握国家、地方、行业多级排放标准体系，并对报告中的产污环节、标准引用、源强核算、达标判定等内容进行逐项核查。人工审核存在效率低、一致性差、新人培养周期长等问题。

近年来，大语言模型（LLM）与检索增强生成（RAG）技术在环评与环境监管领域的应用快速推进，已有多个研究与实践案例：

**国际研究：**
- **NEPAQuAD**：美国太平洋西北国家实验室（PNNL）构建的首个环境影响报告书（EIS）问答基准，覆盖事实查询到复杂问题求解等多种题型。实验表明，RAG 模型在环境监管问答上显著优于纯 LLM 长上下文方案，尤其是在需要精确定位的问题上 [$TRAE_REF](https://arxiv.org/abs/2407.07321)。
- **PNNL RAG vs Long Context 研究**：系统对比了前沿 LLM 在环境审查文档理解中的表现，发现 HippoRAG 等高级 RAG 系统能有效缓解长上下文的"中间迷失"问题，在复杂法规检索任务上优势明显 [$TRAE_REF](https://www.pnnl.gov/sites/default/files/media/file/PNNL_PolicyAI_RAG_Lessons_v3_06_20.pdf)。
- **AI 环境合规模型**：2026 年的行业分析显示，AI 环境合规已形成七层技术栈，LLM 将 EPA、加州 SB 253、欧盟 CSRD 等法规解析为结构化规则图，RAG 是其中核心的知识检索层 [$TRAE_REF](https://gaper.io/ai-ensuring-compliance-environmental-laws)。

**国内实践：**
- **生态环境部环评统建系统**：已上线智能化辅助审批功能，在电机制造、塑料制品等行业试点中，累计辅助审批项目 464 个，发现疑似问题 43 个，涉及产业政策、新污染物、环评降级等方面 [$TRAE_REF](https://www.china-eia.com/gzdt/202512/t20251225_1138994.shtml)。
- **杭州市生态环境局**：私域部署 DeepSeek-R1、Qwen2.5 等大模型，结合专业知识库与知识图谱，开发"大语言模型+报告表生成"智能体，编制时间从 1 个月缩短至 30 分钟；同时构建"AI辅助审批"智能体，整合 80 项审查要点，15 分钟内自动完成质量检查 [$TRAE_REF](https://blog.csdn.net/MCANDML/article/details/149114757)。
- **北京海淀区**：依托大模型与 GIS 实现环评报告合规性预审，将编制周期从 1-3 个月缩短至 1-3 天 [$TRAE_REF](https://sthjj.beijing.gov.cn/bjhrb/index/ztzl/436400273/436400274/743905560/index.html)。

**学术探索：**
- **DeepSeek 环评审核研究**：基于开源 DeepSeek 模型，提出"多模态知识融合-动态风险管控-人机协同迭代"三层智能审核框架，实证结果显示污染物核算错误率从人工审核的 7.2% 降至 0.8%，逻辑缺陷识别准确率显著提升 [$TRAE_REF](http://hjkxdk.yraes.org.cn/cn/article/pdf/preview/ab4992bf-22d0-4b3e-af9a-8f98de1fcbc8.pdf)。
- **相近领域参考**：建筑合规审查领域已出现 GraphRAG（如 Archie、BEST-KAG）等进阶方案，通过知识图谱建模规范条文间的关系，在建筑工程标准问答上显著优于纯文本 RAG [$TRAE_REF](https://www.aecfoundry.com/blog/archie-tranforming-aec-compliance-with-graphrag)。

这些研究与实践共同表明：**RAG 是提升 LLM 在环评等专业领域表现的关键技术路径**。然而，现有研究大多停留在"RAG 有没有用"的验证层面，对于更本质的问题——**RAG 的作用机制是什么、对什么类型的模型最有效、在什么类型的任务上增益最大**——尚缺乏系统的实证研究。

### 1.2 现有研究的共识与空白

基于文献调研，与本研究最相关的核心文献及其发现如下：

| 论文 | 场景 | 核心发现 | 与本研究的关系 |
|---|---|---|---|
| **RAG in the Wild** (ACL 2026) | 通用 QA / 多领域 | RAG 增益主要集中在小模型；模型足够强时增益显著下降，仅事实性 QA 任务仍有提升 | 最直接相关，但在通用领域，未涉及专业法规场景 |
| **To Memorize or to Retrieve** (arXiv 2026) | 通用 QA | 小模型从 RAG 获益最大，3B 左右基本饱和 | 理论基础，但关注点在预训练策略 |
| **Less LLM, More Documents** (arXiv 2025) | 通用 QA / 数学 / 代码 | 小模型 + 大语料可以匹敌更大的模型 | 侧面支持知识替代，但用的是语料扩充而非 RAG |
| **NEPAQuAD** (arXiv 2024) | 环境监管 EIS | RAG 在环境审查问答上显著优于纯 LLM 长上下文 | 同领域证据，但未涉及模型能力梯度 |
| **DeepSeek EIA 审核** (2025) | 环评报告书 | 知识库增强后污染物核算错误率从 7.2% 降至 0.8% | 同领域实践，但未系统对比模型能力 |
| **Legal-DC** (2026) | 法律文档分类 | LegRAG 比 baseline 提升 1.3%-5.6% | 同属法规领域，但任务不同（分类 vs 问答） |
| **DomainRAG** (2024) | 中文多领域 | 领域 RAG 在忠实度、时效性等维度显著优于纯 LLM | 领域 RAG 有效性证据，但未涉及模型缩放 |

**现有研究已达成的共识：**
1. RAG 能有效提升 LLM 在知识密集型任务上的表现
2. RAG 增益随模型能力提升而下降——即存在"知识替代效应"
3. 领域 RAG 在专业场景下优于通用方案

**现有研究尚未回答的问题（本研究空白）：**

**G1：专业法规领域的知识替代效应边界不明确。** 现有研究（RAG in the Wild、To Memorize or to Retrieve）主要在通用 QA 场景验证了知识替代效应，但环评等法规密集型领域具有**标准体系层级多、地方差异大、更新频率高、合规要求严**等特点，模型的内置知识能否覆盖这些长尾专业知识尚不明确。如果强模型在通用知识上饱和但在专业法规知识上仍有显著缺口，则 RAG 在专业领域的价值会持续存在——这构成了对现有知识替代理论的**边界补充**。

**G2：不同知识来源对不同能力模型的增益差异缺乏系统对比。** 现有研究大多只对比"有/无 RAG"的二元条件，未区分知识来源的质量梯度。实际上，AI 辅助系统可以选择多种知识配置：不提供外部知识、接入通用搜索引擎、构建领域知识库。不同能力的模型对知识质量的敏感度可能不同——**弱模型可能"有知识就行"，强模型可能更在意"知识够不够专业"**。这一问题直接影响技术选型策略。

**G3：RAG 增益的任务异质性缺乏基于认知需求的理论化分类。** 现有研究对任务类型的划分较粗（如事实性/推理性），缺乏针对专业审核场景的系统化分类框架。环评审核包含从简单字段抽取到复杂计算链复算的多种任务类型，不同任务对外部知识和推理能力的需求差异很大。如果能建立基于认知需求的任务分类并揭示 RAG 增益的差异规律，将为分场景的 AI 系统建设提供更精准的指导。

### 1.3 核心科学问题

基于上述研究空白，本研究的核心科学问题是：

> **在环评法规密集型场景中，RAG 对审核质量的增益有多大？这种增益如何随模型能力和任务类型变化？是否存在不可替代的边界？**

具体分解为三个子问题：

**子问题 1：RAG 的基础效应**
领域 RAG 相对于纯 LLM，在环评审核任务上是否有显著的性能提升？增益的幅度有多大？

**子问题 2：知识替代效应及其边界**
RAG 的增益是否随模型能力的增强而下降（知识替代效应）？在环评专业法规领域，这种替代效应是否存在边界——即即使最强的模型，在某些类型的知识上仍显著依赖 RAG？

**子问题 3：知识质量与任务类型的调节作用**
不同质量的知识来源（无知识 / 联网搜索 / 领域 RAG）对不同能力模型的增益有何差异？RAG 增益在不同认知需求的任务类型（E×P 四分类）上有何不同规律？

### 1.4 研究贡献与创新点

| 研究空白 | 创新点 | 贡献 |
|---|---|---|
| **G1：专业领域知识替代效应的边界不明确** | **I1：首次在环评法规密集型场景中系统验证知识替代效应的存在与边界**。通过 3 档模型 × 3 种知识条件的析因设计，揭示强模型在通用知识上饱和、但在地方标准等长尾专业知识上仍显著依赖 RAG 的现象 | **理论贡献**：拓展了知识替代效应的适用边界，发现专业法规领域存在"不可替代的知识"，为 RAG scaling 理论提供了新的实证证据 |
| **G2：不同知识来源对不同能力模型的增益差异不清** | **I2：构建三档知识质量的对比框架，揭示"弱模型缺量、强模型缺专"的规律**。系统对比无外部知识 / 联网搜索 / 领域 RAG 三种条件在不同能力模型上的表现 | **方法贡献**：建立知识质量梯度的分析框架，为 RAG 系统选型提供更细粒度的决策依据——不是简单的"要不要 RAG"，而是"什么模型配什么级别的知识" |
| **G3：RAG 增益的任务异质性缺乏理论化分类** | **I3：基于 E×P 二维框架的任务异质性分析**。将环评审核任务按外部知识依赖性（E）和程序复杂度（P）分为四类，揭示 RAG 增益和模型能力差异在不同任务类型上的各自规律 | **实践贡献**：为环评 AI 辅助系统的分场景建设提供实证依据，不同类型的审核题应匹配不同的模型和知识配置策略 |

## 2 研究设计

### 2.1 总体研究框架

本研究采用**模型能力（3 档）× 知识来源（3 档）**的 3×3 析因实验设计，辅以 EP 任务分类的分层分析和消融实验，系统考察 RAG 在环评审核中的作用机制。

```
                    ┌─────────────────────────────────┐
                    │       因变量：审核质量            │
                    │  正确率 / 忠实度 / 推理完整度     │
                    └───────────────┬─────────────────┘
                                    │
            ┌───────────────────────┼───────────────────────┐
            ▼                       ▼                       ▼
    ┌───────────────┐       ┌───────────────┐       ┌───────────────┐
    │  自变量 1      │       │  自变量 2      │       │  调节变量      │
    │  模型能力      │       │  知识来源      │       │  任务类型      │
    │  (3 档)       │       │  (3 档)       │       │  (EP 四分类)   │
    │               │       │               │       │               │
    │ A1: qwen-flash│       │ K1: 无知识    │       │ E0P0: 字段抽取 │
    │ A2: qwen-plus │       │ K2: 联网搜索  │       │ E1P0: 标准查阅 │
    │ A3: qwen-max  │       │ K3: 领域 RAG  │       │ E0P1: 一致性   │
    │               │       │               │       │ E1P1: 计算复算 │
    └───────────────┘       └───────────────┘       └───────────────┘
```

### 2.2 3×3 析因设计

| | 无外部知识 (K1) | 联网搜索 (K2) | 领域 RAG (K3) |
|---|---|---|---|
| **弱模型** (A1: qwen3.8-flash) | A1K1 | A1K2 | A1K3 |
| **中模型** (A2: qwen3.7-plus) | A2K1 | A2K2 | A2K3 |
| **强模型** (A3: qwen3.8-max) | A3K1 | A3K2 | A3K3 |

**核心对比：**

| 对比 | 检验的问题 | 对应假设 |
|---|---|---|
| K3 vs K1（RAG 主效应） | RAG 有没有用？ | H1 |
| K2 vs K1（联网主效应） | 联网搜索有没有用？ | H1 |
| K3 vs K2（RAG vs 联网） | 领域 RAG 比联网搜索好多少？ | H4 |
| A1 下 (K3-K1) vs A3 下 (K3-K1) | 知识替代效应（弱模型增益 vs 强模型增益） | H3 |
| A1 下 (K2-K1) vs A3 下 (K2-K1) | 联网搜索的替代效应是否更快？ | H4 |

### 2.3 研究假设

**H1（知识来源主效应）：** 三种知识条件的审核正确率存在显著差异，表现为领域 RAG > 联网搜索 > 无外部知识。

**H2（模型能力主效应）：** 三档模型的审核正确率存在显著差异，表现为强模型 > 中模型 > 弱模型。

**H3（知识替代效应）：** 模型能力与知识来源存在显著交互效应——RAG 相对于无知识的增益随模型能力提升而递减（弱模型增益 > 中模型 > 强模型）。

**H4（知识质量调节效应）：** 联网搜索的增益随模型能力提升衰减得更快（强模型的 K2-K1 趋近于 0），但领域 RAG 的增益衰减较慢——即弱模型"有知识就行"，强模型更需要"专业知识"。

**H5（领域知识不可替代性）：** 在地方标准、行业细则等长尾知识题（E1P0 子类）上，即使最强模型的 RAG 增益仍然显著——知识替代效应存在边界。

**H6（任务异质性）：** RAG 增益因任务类型而异，表现为 E1P0 > E1P1 > E0P1 > E0P0。E 维度决定 RAG 增益上限，P 维度决定模型能力差异幅度。

**H7（过程质量效应）：** RAG 不仅提升正确率，还提升答案的忠实度和证据引用准确率；强模型在过程质量上的基线更高，但 RAG 仍有增量提升。

### 2.4 消融实验设计

为排除混淆因素、确保观测到的 RAG 增益确实来自知识内容本身，增设两组消融条件：

| 消融组 | 条件 | 排除的替代解释 | 预期结果 |
|---|---|---|---|
| **R0：空上下文控制组** | prompt 中保留「以下是检索结果：」格式标记，但检索内容为空（或"未检索到相关结果"） | 格式安慰剂效应 / 任务暗示效应（"有检索这个动作"本身就让模型更认真） | 正确率与 K1（无知识）无显著差异 |
| **R1：噪声知识组** | 检索结果为不相关的通用环保知识（如环保科普、环境新闻） | 文本量效应（只要输入变长就有用） | 正确率与 K1 无显著差异，或略降（干扰效应） |

**消融逻辑链：**
```
K1 vs R0 → 排除"格式/暗示效应"
R0 vs R1 → 排除"文本量效应"  
R1 vs K3 → 验证"知识质量效应"
```
如果 K3 > R1 = R0 = K1，则可以确定 RAG 增益来自**正确的领域知识内容**。

> **实施策略**：优先做 R0（空上下文控制组），成本最低且排除最大混淆因素。如果结果显示 K3 > R0 且 R0 ≈ K1，则足以支撑因果结论；R1 视时间和资源情况决定是否补充。

## 3 实验方法

### 3.1 模型选择与配置

采用 Qwen 同家族三档模型，控制架构差异，仅能力规模不同：

| 档位 | 模型 ID | 定位 | 预期能力差异 |
|---|---|---|---|
| 弱 (A1) | `qwen3.8-flash` | 快速、低成本版本 | 内置知识有限，推理能力较弱 |
| 中 (A2) | `qwen3.7-plus` | 效果与成本均衡版本 | 能力显著强于 flash，内置知识更丰富 |
| 强 (A3) | `qwen3.8-max` | 旗舰版本 | 最强能力，内置知识最广，推理最强 |

**统一参数配置：**
- 温度 (temperature)：0.1（低随机性，保证可复现性）
- max_tokens：4096
- 接口地址：`https://one-hub.hycx-gd.cn/`
- 重复次数：每组 3 次（降低随机性影响，取众数作为最终答案）

### 3.2 知识条件实现

#### 3.2.1 K1：无外部知识（基线）

prompt 仅包含任务说明、审核题目和报告片段，不提供任何外部知识。

#### 3.2.2 K2：联网搜索（中间质量）

**主方案：搜索 API + snippet 拼接**

参考 LiveNewsBench、Frustratingly Simple Retrieval 等论文的标准做法：

| 配置项 | 设计 | 说明 |
|---|---|---|
| 检索方式 | 搜索 API（Bing Web Search API 或同类） | 固定接口，结果可控可复现 |
| 检索数量 | top-5 | 平衡信息量与噪声 |
| 查询构造 | 直接用审核题目作为查询 | 不做查询改写，保持简洁 |
| 结果处理 | 取每个结果的标题 + snippet + URL | 不抓取完整网页，避免解析不确定性 |
| 上下文组织 | 按检索顺序编号，拼接成"检索结果"段落 | 与 RAG 条件格式一致 |
| 位置 | 放在题目之前，系统提示之后 | 标准 RAG 格式 |

**备选方案：RAG + 噪声文档模拟**（搜索 API 不可用时）

用现有领域 RAG 知识库 + 混入 30-50% 噪声文档（通用环保知识、不相关法规），模拟联网搜索的"有信息但有干扰"场景。

#### 3.2.3 K3：领域 RAG（高质量）

使用环评法规知识库 RAG 系统：
- 知识库内容：国家/地方/行业排放标准、环评技术导则、产业政策等
- 检索方式：向量检索 + 重排序
- 检索数量：top-5 最相关文档片段
- 上下文组织：按相关度排序，标注来源标准名称和条款号

### 3.3 评价集

#### 3.3.1 总体设计

| 项目 | 说明 |
|---|---|
| **题目数量** | ~40 题（开发集） |
| **题目来源** | 从真实环评报告中人工抽取审核点 |
| **EP 分布** | E0P0 × ~10、E1P0 × ~10、E0P1 × ~10、E1P1 × ~10 |
| **金标准** | 人工编制参考答案（标准依据 + 正确结论） |
| **标注流程** | 2 名标注者独立标注 → 不一致处讨论解决 → 最终审定 |
| **标注一致性** | Cohen's kappa 系数（待计算，目标 ≥ 0.8） |

#### 3.3.2 题目来源扩充

现有资源：
- **pilot16 FROZEN**：16 题，已冻结金标准，分类置信度 HIGH ✅
- **paired_48**：48 题，有答案但缺 EP 标注 → 可筛选补充 E1P0/E1P1 类型
- **heldout16_v3**：73 题，冻结测试集 → 最终验证用

**扩充方案**：从 paired_48 中筛选 E1P0 和 E1P1 类型题目（约 20-25 题），补充 EP 标注和金标准核验，将开发集扩充到 ~40 题。

#### 3.3.3 EP 任务分类体系

基于环评审核的认知特征，采用 **E（外部知识依赖性）× P（程序复杂度）** 的二维任务分类框架：

- **E 维度（External Knowledge Dependency）**：完成该审核任务是否需要报告以外的外部知识（排放标准、产业政策、技术规范等）
- **P 维度（Procedural Complexity）**：完成该审核任务所需的推理步骤复杂度

**理论意义**：E 维度决定 RAG 增益的上限，P 维度决定模型能力差异的幅度。通过四分类，可以分离"知识"和"推理"两个因素对审核质量的各自贡献。

| 类型 | 名称 | 题数 | 说明 | 预期 RAG 增益 |
|---|---|---:|---|---|
| **E0P0** | 字段抽取类 | ~10 | 纯文本抽取，如产量、定员、占地面积等 | 最低（接近 0） |
| **E1P0** | 标准查阅类 | ~10 | 纯知识核验，如排放标准限值、危废类别判定 | 最高 |
| **E0P1** | 报告一致性类 | ~10 | 纯逻辑推理，如前后数据一致性、比例计算 | 低 |
| **E1P1** | 计算链复算类 | ~10 | 知识+推理综合运用，如源强核算、收集效率计算 | 中等 |

### 3.4 评价指标体系

#### 第一层：结果正确性（核心指标）

| 指标 | 定义 | 计算方式 |
|---|---|---|
| **结论正确率** | 审核结论（匹配/不匹配/无法判断/不适用）与参考答案一致的比例 | Correct / Total |
| **多数投票正确率** | 3 次重复取众数后的正确率 | 模拟实际部署策略 |
| **精确率 / 召回率 / F1** | 针对二分类题（匹配/不匹配）的分类性能 | 标准分类指标 |
| **答案正确性（Answer Correctness）** | 答案事实准确性 + 语义相似度（参考 RAGAS） | 基于参考答案的事实提取与比对 |

#### 第二层：过程质量（解释性指标）

| 指标 | 定义 | 适用条件 |
|---|---|---|
| **证据忠实度（Faithfulness）** | 答案中的陈述有多少能被给定上下文支持（参考 RAGAS） | K2 / K3 |
| **上下文召回率（Context Recall）** | 参考答案中的信息有多少被检索上下文覆盖 | K2 / K3 |
| **答案相关性（Answer Relevancy）** | 答案是否直接回应问题，有无答非所问 | 全部条件 |
| **推理链完整度** | "问题识别→证据引用→比对分析→结论给出"四步完整度 | 全部条件 |
| **证据引用准确率** | 引用的标准名称、编号、条款号是否准确（参考 FActScore 原子事实法） | K2 / K3 |

#### 第三层：错误类型分析（诊断性指标）

| 错误类型 | 定义 | 对应假设 |
|---|---|---|
| **知识缺失错误** | 因不知道相关标准/政策而答错 | H1, H3, H5 |
| **幻觉错误** | 编造不存在的标准编号、限值等 | H7（忠实度） |
| **检索遗漏错误** | 正确答案在知识库中但没检索到 | K3 特有 |
| **推理错误** | 知识正确但推理过程出错（计算错误、逻辑漏洞） | H2, H6（P维度） |
| **证据误用错误** | 检索到了正确信息但理解/使用错误 | H4, H7 |

### 3.5 人工效度验证

为验证自动评价指标的可靠性，抽取部分样本进行人工评分：

| 项目 | 设计 |
|---|---|
| **抽样方法** | 分层抽样：9 组条件各抽 3 题 × 1 次重复 = 27 个样本 |
| **评估维度** | 1）结论正确性；2）事实准确性；3）推理完整性；4）证据引用准确性 |
| **评分量表** | 5 分制（1=完全错误，5=完全正确） |
| **评估者** | 2 名具有环评专业背景的评估者，独立评分 |
| **一致性检验** | 计算评估者间一致性（ICC 系数） |
| **指标验证** | 计算自动评价指标与人工评分的 Pearson / Spearman 相关系数 |

> **降级方案**：如果资源有限，至少做 10 份人工评估，证明自动指标与人工判断方向一致。

### 3.6 统计方法

- **双因素 ANOVA**：检验模型能力、知识来源的主效应和交互效应
- **事后检验**：Tukey HSD 多重比较
- **Bootstrap 置信区间**：1000 次重采样，计算 95% CI
- **效应量**：偏 eta 方（η²ₚ）
- **分层分析**：按 EP 类型分别进行统计检验
- **显著性水平**：α = 0.05

### 3.7 实验规模

**主体实验（3×3）：**
- 9 组条件 × ~40 题 × 3 次重复 = **~1080 次 API 调用**

**消融实验（R0）：**
- 3 模型 × ~40 题 × 3 次重复 = **~360 次调用**

**合计（推荐版）：~1440 次调用**

## 4 预期结果与故事线

### 4.1 预设主要结果

**R1（RAG 有效）：** 领域 RAG 相对于无知识，整体正确率提升 20-35 个百分点，且提升具有统计显著性。弱模型提升幅度最大（~35%），强模型仍有显著提升（~15%）。

**R2（知识替代有边界）：** 知识替代效应整体成立（RAG 增益随模型能力下降），但在地方标准等长尾知识题（E1P0 子类）上，即使最强模型仍有 20%+ 的 RAG 增益——存在"不可替代的边界"。

**R3（联网衰减更快）：** 联网搜索对弱模型有一定增益（~15%），但对强模型增益很小（~5%），显著低于领域 RAG。说明弱模型"有知识就行"，强模型更需要"专业知识"。

**R4（任务异质性）：** RAG 增益按 E1P0 > E1P1 > E0P1 > E0P0 递减。E0P0 题上三组知识条件无显著差异（控制题验证通过）。

### 4.2 核心故事线

论文的叙事逻辑按照以下递进关系展开：

```
第 1 层：RAG 在环评审核中有用吗？
  → 有用（R1），基础效应成立
  
第 2 层：RAG 对谁更有用？
  → 对弱模型更有用，但强模型仍有增益（R2）
  → 引出：知识替代效应存在但有边界
  
第 3 层：边界在哪里？
  → 地方标准、行业细则等长尾知识是边界（R2 细化）
  → 这是专业领域与通用领域的关键区别
  
第 4 层：知识质量重要吗？
  → 对弱模型不重要，对强模型重要（R3）
  → "弱模型缺量，强模型缺专"
  
第 5 层：不同任务都一样吗？
  → 不一样，E1P0 增益最大，E0P0 几乎为零（R4）
  → E 和 P 两个维度各自有不同的影响规律
```

### 4.3 典型案例规划

从实验结果中选取 4 类典型案例，用于结果章节的深度展示：

| 案例类型 | 选题方向 | 展示目的 |
|---|---|---|
| **知识替代案例** | E1P0 题，弱模型 A 错 C 对，强模型 A 也对 | 直观展示知识替代效应 |
| **知识不可替代案例** | 地方标准题，强模型 A 错 C 对 | 核心发现的具象化——"边界"的具体体现 |
| **联网不够案例** | B 错 C 对的题（如行业特有标准） | 解释领域 RAG 为什么比联网搜索好 |
| **推理不足案例** | E0P1 题，弱模型错，强模型对，RAG 没用 | 说明 P 维度的独立作用 |
