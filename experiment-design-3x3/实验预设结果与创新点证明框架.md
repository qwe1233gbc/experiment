## 一、核心问题：怎么证明"RAG 有用"？

### 1.1 证明的三层逻辑

证明 RAG 有用不是一句话的事，需要三层证据环环相扣：

```
第一层：RAG 之后正确率确实提高了
    ↓ （排除混淆因素）
第二层：提高是因为 RAG 提供了正确的领域知识，而不是其他原因
    ↓ （揭示作用机制）
第三层：RAG 的作用有规律——对什么题、对什么模型、在什么边界上有用
```

每一层对应不同的实验设计和指标：

| 层级 | 要证明的事 | 用什么证明 | 对应的实验条件 |
|------|-----------|-----------|--------------|
| **第一层** | RAG 提升了正确率 | 结论正确率对比（K3 vs K1） | 主体实验 3×3 |
| **第二层** | 提升来自正确的领域知识 | 消融实验（K1 vs R0 vs R1 vs K3） | 消融实验 R0/R1 |
| **第三层** | 提升有规律（任务/模型/边界） | EP 分层分析 + 过程指标 + 错误类型 | 分层分析 |

### 1.2 为什么只说"正确率提高了"不够？

如果只报告"加了 RAG 之后正确率从 50% 升到 75%"，审稿人会问：

1. **会不会是 prompt 变长了所以模型更认真？** → 需要 R0 消融组
2. **会不会是模型看到"检索结果"这几个字就更谨慎了？** → 需要 R0 消融组
3. **会不会是随便加点什么文本都有用？** → 需要 R1 消融组
4. **提升是因为知识还是因为格式？** → 需要过程指标（证据引用准确率是否同步提升）
5. **提升是普遍的还是只在某类题上？** → 需要 EP 分层分析
6. **是所有模型都受益还是只有弱模型受益？** → 需要交互效应分析

**所以，证明 RAG 有用 = 主效应 + 消融 + 分层 + 过程指标，四件套缺一不可。**

## 二、预设结果矩阵

### 2.1 整体正确率预设（9 个格子）

基于已有研究和常识，预设各条件下的整体正确率：

| | 无外部知识 (K1) | 联网搜索 (K2) | 领域 RAG (K3) | RAG 增益 (K3-K1) |
|---|---|---|---|---|
| **弱模型 (A1)** | 40-50% | 55-65% | 70-80% | **+25~30%** |
| **中模型 (A2)** | 55-65% | 65-72% | 80-88% | **+20~25%** |
| **强模型 (A3)** | 65-75% | 70-78% | 85-92% | **+15~20%** |

**关键数值判断：**

- 如果 A1K3 - A1K1 ≥ 20% → RAG 对弱模型效果显著 ✅
- 如果 A3K3 - A3K1 ≥ 10% → 强模型仍有显著增益，支持"有边界" ✅
- 如果 A1(K3-K1) > A3(K3-K1) → 知识替代效应成立 ✅
- 如果 K2-K1 在 A1 上 >10% 但在 A3 上 <5% → 联网衰减更快 ✅

### 2.2 EP 四类题的预设正确率

这是最关键的分层分析，直接支撑创新点 I3。

#### E0P0（字段抽取类，~10 题）

预设：三组知识条件几乎无差异，模型能力差异也小。

| | K1 | K2 | K3 | RAG 增益 |
|---|---|---|---|---|
| A1 弱模型 | 70-80% | 70-80% | 70-80% | ~0% |
| A2 中模型 | 80-90% | 80-90% | 80-90% | ~0% |
| A3 强模型 | 85-95% | 85-95% | 85-95% | ~0% |

**判断标准**：RAG 增益 < 5%，说明 E0P0 是有效的"控制题"——纯报告内信息，外部知识确实帮不上忙。
**如果相反**（RAG 增益 > 10%），说明题目分类有问题，需要重新检查 EP 标注。

#### E1P0（标准查阅类，~10 题）

预设：RAG 增益最大，且强模型仍有显著增益（不可替代的证据）。

| | K1 | K2 | K3 | RAG 增益 |
|---|---|---|---|---|
| A1 弱模型 | 20-30% | 40-50% | 65-75% | **+40~45%** |
| A2 中模型 | 35-45% | 50-60% | 75-85% | **+35~40%** |
| A3 强模型 | 50-60% | 60-70% | 85-95% | **+25~35%** |

**关键判断**：
- A3K3 - A3K1 ≥ 20% → 强模型在标准知识题上仍有大幅提升 → **知识不可替代的核心证据** ✅
- K3-K2 > 10%（尤其在 A3 上）→ 领域 RAG 显著优于联网搜索 → 支持 H4 ✅
- 细分：地方标准题的 RAG 增益 > 国家标准题 → **长尾知识更不可替代** ✅

#### E0P1（报告一致性/复算类，~10 题）

预设：模型能力差异大，RAG 增益小。

| | K1 | K2 | K3 | RAG 增益 |
|---|---|---|---|---|
| A1 弱模型 | 25-35% | 25-35% | 30-40% | **+5~10%** |
| A2 中模型 | 45-55% | 45-55% | 50-60% | **+5%** |
| A3 强模型 | 60-70% | 60-70% | 65-75% | **+5%** |

**关键判断**：
- 模型间差异（A3K1 - A1K1）> 30% → P 维度（推理能力）影响大 ✅
- RAG 增益 < 10% → 纯推理题，外部知识帮不上太多 ✅
- 错误类型主要是推理错误/计算错误 → 支持 P 维度的解释 ✅

#### E1P1（计算链复算/综合类，~10 题）

预设：RAG 有中等增益，模型能力也有显著影响。

| | K1 | K2 | K3 | RAG 增益 |
|---|---|---|---|---|
| A1 弱模型 | 20-30% | 30-40% | 55-65% | **+30~35%** |
| A2 中模型 | 35-45% | 45-55% | 70-80% | **+30~35%** |
| A3 强模型 | 50-60% | 60-70% | 80-90% | **+25~30%** |

**关键判断**：
- RAG 增益介于 E1P0 和 E0P1 之间 → 符合预期（需要知识也需要推理）✅
- 模型间差异也较大 → P 维度同时在起作用 ✅
- 过程指标：K3 条件下"知识应用准确率"显著高于 K1 → 支持 RAG 的作用机制 ✅

### 2.3 四类题 RAG 增益排序预期

```
E1P0 (+30~40%) > E1P1 (+25~35%) > E0P1 (+5~10%) ≈ E0P0 (~0%)
```

这个排序如果成立，就完美支持了你的核心理论框架：
- **E 维度决定 RAG 增益上限**（E1 类 > E0 类）
- **P 维度决定模型能力差异幅度**（P1 类的模型间差异 > P0 类）

## 三、每个创新点的证据链

### 3.1 创新点 I1：专业法规领域存在知识替代效应的边界

**要证明的事**：知识替代效应整体成立（强模型 RAG 增益 < 弱模型），但在专业法规领域存在边界——即使最强模型，在某些知识上仍显著依赖 RAG。

**证据链**：

```
证据 1（主效应+交互效应）：
  ├── 双因素 ANOVA 显示知识来源主效应显著（p < 0.05）
  ├── 模型能力主效应显著（p < 0.05）
  └── 交互效应显著（p < 0.05）→ 支持"知识替代效应"
       ↓
证据 2（增益递减的定量证据）：
  ├── 弱模型 RAG 增益 = X%（如 +28%）
  ├── 中模型 RAG 增益 = Y%（如 +22%）
  ├── 强模型 RAG 增益 = Z%（如 +16%）
  └── X > Y > Z → 递减趋势成立
       ↓
证据 3（边界存在的核心证据——E1P0 分层分析）：
  ├── E1P0 题上，强模型 RAG 增益仍 ≥ 20%
  ├── 细分：地方标准题增益 > 国家标准题增益
  └── 结论：强模型在长尾专业知识上仍有显著缺口 → 边界存在
       ↓
证据 4（错误类型佐证）：
  ├── 无知识条件下，强模型在 E1P0 题上的错误主要是"知识缺失"
  ├── 加了 RAG 后，知识缺失错误大幅减少
  └── 说明确实是知识缺口限制了表现，不是推理能力问题
```

**如果结果不符合预期怎么办？**

| 意外结果 | 可能的解释 | 怎么圆 |
|---------|-----------|-------|
| 强模型 RAG 增益也很大（>25%） | 环评专业知识确实是强模型的盲区 | 更好！边界效应更明显，反而强化 I1 |
| 强模型 RAG 增益很小（<10%） | Qwen-max 内置知识已经覆盖了环评标准 | 弱化 I1，但可以转成"环评领域知识替代效应比通用领域更快饱和"——仍然是新发现 |
| 增益没有递减（强模型增益 ≥ 弱模型） | 几乎不可能，但如果出现：可能弱模型太弱不会用检索结果 | 需要分析过程指标，看是不是弱模型"有知识但不会用" |

### 3.2 创新点 I2：弱模型缺量、强模型缺专

**要证明的事**：不同质量的知识来源对不同能力模型的增益不同——弱模型"有知识就行"，强模型更需要"专业知识"。

**证据链**：

```
证据 1（联网搜索的增益衰减更快）：
  ├── 弱模型：K2-K1 = ~15%（有提升）
  ├── 中模型：K2-K1 = ~10%（提升变小）
  ├── 强模型：K2-K1 = ~5%（几乎没提升）
  └── 联网搜索的增益随模型能力快速衰减
       ↓
证据 2（领域 RAG 的增益衰减更慢）：
  ├── 弱模型：K3-K1 = ~28%
  ├── 中模型：K3-K1 = ~22%
  ├── 强模型：K3-K1 = ~16%
  └── 领域 RAG 增益也在衰减，但衰减速度慢于联网搜索
       ↓
证据 3（K3-K2 的差值在强模型上更大）：
  ├── 弱模型：K3-K2 = ~13%（领域比联网好一点）
  └── 强模型：K3-K2 = ~11%？不对，应该是...
  重新想：
  ├── 弱模型：K2-K1 = 15%，K3-K1 = 28% → K3 比 K2 好 13%
  ├── 强模型：K2-K1 = 5%，K3-K1 = 16% → K3 比 K2 好 11%？
  不对，这说不通。换个角度：
  ├── 弱模型：K2/K1 的提升比 = 15% → "有知识就行"，联网也能补很多
  └── 强模型：K2/K1 的提升比 = 5%，但 K3/K1 仍有 16% → 只有专业知识才有用
  这样就对了！
       ↓
证据 4（过程指标佐证——标准引用准确率）：
  ├── 弱模型 K2 和 K3 的引用准确率差不多 → 弱模型不挑知识质量
  └── 强模型 K3 的引用准确率显著高于 K2 → 强模型能区分知识质量
```

**用一句话总结 I2 的证明逻辑**：
> 弱模型加联网已经提升很多（+15%），加领域 RAG 再提升一些（+13% 额外）；
> 强模型加联网几乎没提升（+5%），但加领域 RAG 仍有大幅提升（+16%）。
> → 弱模型缺的是"有没有知识"，强模型缺的是"知识够不够专业"。

**如果结果不符合预期怎么办？**

| 意外结果 | 可能的解释 | 调整方向 |
|---------|-----------|---------|
| 强模型加联网也有很大提升 | 联网搜索质量比预期好 | 弱化 I2，但可以讨论"高质量搜索也能部分替代领域 RAG" |
| 弱模型加领域 RAG 提升不如联网 | 弱模型不会利用结构化知识 | 可以做一个子分析：弱模型是不是检索了但没用到？ |
| K2 和 K3 差异很小 | 知识库内容可以被搜索替代 | 需要反思知识库的独特价值在哪里——可能是地方标准等搜索不到的内容 |

### 3.3 创新点 I3：基于 E×P 二维框架的任务异质性分析

**要证明的事**：RAG 增益和模型能力差异在不同任务类型上有不同规律——E 维度决定 RAG 增益上限，P 维度决定模型能力差异幅度。

**证据链**：

```
证据 1（E 维度的效应——E1 类 RAG 增益 > E0 类）：
  ├── E0P0 RAG 增益 ≈ 0%
  ├── E1P0 RAG 增益 ≈ 30-40%
  ├── E0P1 RAG 增益 ≈ 5-10%
  ├── E1P1 RAG 增益 ≈ 25-35%
  └── 同一个 P 水平下，E1 总是 > E0 → E 维度决定 RAG 增益
       ↓
证据 2（P 维度的效应——P1 类模型差异 > P0 类）：
  ├── E0P0：A3K1 - A1K1 ≈ 15%（模型差异较小）
  ├── E0P1：A3K1 - A1K1 ≈ 35%（模型差异大）
  ├── E1P0：A3K1 - A1K1 ≈ 30%（模型差异中等）
  ├── E1P1：A3K1 - A1K1 ≈ 35%（模型差异大）
  └── 同一个 E 水平下，P1 总是 ≥ P0 → P 维度决定模型能力差异
       ↓
证据 3（排序验证）：
  ├── RAG 增益排序：E1P0 > E1P1 > E0P1 > E0P0
  └── 模型差异排序：E0P1 ≈ E1P1 > E1P0 > E0P0
       ↓
证据 4（过程指标佐证）：
  ├── E0 类题：错误主要是提取/推理错误 → 知识不是瓶颈
  ├── E1 类题：错误主要是知识缺失/幻觉 → 知识是瓶颈
  ├── P0 类题：步骤简单，模型间差异主要来自知识量
  └── P1 类题：步骤复杂，模型间差异来自知识 + 推理双重因素
```

**如果结果不符合预期怎么办？**

| 意外结果 | 可能的解释 | 调整方向 |
|---------|-----------|---------|
| E0P0 RAG 增益也不小 | 题目分类有问题，或者 RAG 提供了间接帮助 | 重新检查 E0P0 题目的分类，可能某些题实际需要外部知识 |
| E1P0 RAG 增益不如 E1P1 | 标准题太简单？或者复算题 RAG 帮助更大？ | 需要看过程指标：是不是 E1P1 中 RAG 帮助了公式理解？ |
| P 维度效应不明显 | 题目可能不够难，天花板效应 | 可以在讨论中说明本研究 P 维度的跨度有限，未来可以设计更难的题 |

## 四、7 个假设的验证标准

每个假设都给一个明确的"通过/不通过"判断标准，实验后直接对照。

### H1（知识来源主效应）✅

**判断标准**：
- 双因素 ANOVA：知识来源主效应 p < 0.05
- 事后检验：K3 > K2 > K1，且至少 K3 vs K1 显著
- 整体 RAG 增益 ≥ 15 个百分点

**如果不通过**：RAG 没用 → 论文就不用写了，直接换方向。（但概率极低）

### H2（模型能力主效应）✅

**判断标准**：
- 双因素 ANOVA：模型能力主效应 p < 0.05
- 事后检验：A3 > A2 > A1，至少 A3 vs A1 显著
- 强模型比弱模型整体高 ≥ 20 个百分点

**如果不通过**：模型能力没差异 → 说明题目太简单或太难，天花板/地板效应。

### H3（知识替代效应）✅

**判断标准**：
- 双因素 ANOVA：模型 × 知识 交互效应 p < 0.05
- 增益递减：A1(K3-K1) > A2(K3-K1) > A3(K3-K1)
- 趋势检验：线性趋势显著

**如果不通过**：
- 如果增益没有递减 → 环评领域知识替代效应不成立 → 反而更有价值（颠覆已有结论）
- 如果强模型增益为 0 → 知识完全替代 → I1（边界）就不成立了，但 I2（知识质量）可能还有意义

### H4（知识质量调节效应）✅

**判断标准**：
- 联网搜索增益：A1(K2-K1) > A3(K2-K1)（衰减快）
- 领域 RAG 增益：A1(K3-K1) > A3(K3-K1)（也衰减，但慢）
- 关键：A3(K3-K1) > A3(K2-K1)，且差值 ≥ 10%
- 即：强模型上，领域 RAG 比联网搜索好很多

**如果不通过**：
- 如果 K2 和 K3 在强模型上差不多 → 弱化 I2
- 如果 K2 在强模型上也很好 → 说明搜索质量足够高时可以替代领域 RAG

### H5（领域知识不可替代性）✅

**判断标准**：
- E1P0 题上，A3K3 - A3K1 ≥ 20%
- 细分：地方标准题的增益 > 国家标准题的增益
- 错误类型：A3K1 在 E1P0 上的错误以"知识缺失"为主（>60%）

**这是 I1 的核心证据，也是论文最有特色的发现。**

**如果不通过**：
- 如果强模型在 E1P0 上增益 < 10% → 强模型内置知识已经覆盖了环评标准
- 可以转向："环评领域知识替代效应饱和更快"——也是一个有价值的发现

### H6（任务异质性）✅

**判断标准**：
- RAG 增益排序：E1P0 > E1P1 > E0P1 > E0P0
- E 维度主效应：E1 类 RAG 增益显著高于 E0 类
- P 维度主效应：P1 类模型间差异显著大于 P0 类
- （可选）三因素 ANOVA：E × P × 知识 三阶交互显著

**如果不通过**：
- 排序不对 → 需要重新理解任务分类的理论基础
- 但至少 E1 > E0 应该成立，否则 RAG 的作用机制就说不通了

### H7（过程质量效应）✅

**判断标准**：
- K3 条件下的证据忠实度 > K2 > K1
- K3 条件下的证据引用准确率 > K2 > K1
- 强模型的过程质量基线（K1）高于弱模型
- RAG 对过程质量的提升在强模型上也存在

**如果不通过**：
- 如果 RAG 提升了正确率但没提升过程质量 → 可能是"蒙对的"，需要仔细检查
- 如果 K2 的忠实度比 K3 还高 → 可能搜索结果更准确？需要具体分析

## 五、结果分析的"剧本"

实验跑完后，按这个顺序分析，每一步都有明确的产出：

### 第一步：算整体正确率（1 小时）

- 9 个格子的正确率、标准差、置信区间
- 画出 3×3 热力图
- 做双因素 ANOVA，看主效应和交互效应
- → 验证 H1、H2、H3

### 第二步：EP 分层分析（2-3 小时）

- 四类题分别算 9 个格子的正确率
- 画 4 个小热力图，或者一张 4 面板的图
- 每类题单独做 ANOVA
- → 验证 H5、H6

### 第三步：过程指标分析（3-4 小时）

- 计算各条件下的过程指标得分
- 看过程指标和正确率的相关性
- 分析 RAG 是通过提升什么过程来提升正确率的
- → 验证 H7

### 第四步：错误类型分析（3-4 小时）

- 标注所有错误答案的错误类型（知识缺失/幻觉/推理错误/检索遗漏/证据误用）
- 按条件分组统计错误分布
- 画错误类型堆叠条形图
- → 深度诊断，支撑讨论章节

### 第五步：消融分析（1-2 小时，如果做了消融）

- K1 vs R0 vs K3 对比
- 如果 R0 ≈ K1 且 K3 > R0 → 增益来自知识内容，不是格式
- → 强化因果结论

### 第六步：典型案例挑选（2-3 小时）

- 从结果中找 4 类代表性案例
- 每个案例整理题目、金标准、不同条件下的答案对比
- → 结果章节的"血肉"

## 六、可能出现的"意外好结果"和"意外坏结果"

### 6.1 意外好结果（赚到了）

| 意外好结果 | 意味着什么 | 可以加的分析 |
|-----------|-----------|-------------|
| E0P1 题上 RAG 也有显著增益 | RAG 不仅提供知识，还帮助了推理？ | 做过程分析：是不是 RAG 提供了计算模板/公式，间接帮助了推理？ |
| 联网搜索在某些题上比领域 RAG 还好 | 搜索的时效性优势 | 细分：哪些题 K2 > K3？是不是最新出台的标准？ |
| 弱模型 + RAG ≥ 强模型无知识 | 知识可以替代能力 | 计算"知识替代的等效模型能力提升"——相当于提升了几个档位？ |
| 某类题正确率 > 90% | 天花板效应 | 说明这类题对当前模型+知识已经饱和，未来可以设计更难的题 |

### 6.2 意外坏结果（要准备好解释）

| 意外坏结果 | 可能的原因 | 怎么应对 |
|-----------|-----------|---------|
| RAG 增益很小（<10%） | ① 题目太简单 ② 模型内置知识已经够用 ③ 检索质量差 | 检查 E1P0 分层，如果 E1P0 增益也小 → 确实是模型太强；如果 E1P0 增益大但整体被 E0 稀释了 → 正常，分层分析就能说清楚 |
| 模型间差异很小 | 题目太难或太简单，天花板/地板效应 | 看每类题的正确率，如果都在 50% 左右说明太难，如果都在 90% 说明太简单 |
| 交互效应不显著 | 增益递减趋势不明显 | 做简单效应分析，看每个模型水平下知识的效应 |
| R0 组正确率比 K1 还高 | 格式提示效应真的存在 | 这反而是一个有趣的发现！可以单独讨论"prompt 结构的暗示效应" |
| 假阳性率特别高 | 模型过度自信/爱挑错 | 讨论 RAG 系统的"审核偏向性"——是偏严还是偏松？在环评场景下的意义 |

### 6.3 最稳妥的"保底发现"

即使所有假设都不那么理想，以下这些几乎一定成立，可以作为论文的保底贡献：

1. **RAG 在环评审核中有效**——至少 E1P0 题上增益肯定显著
2. **不同任务类型的 RAG 增益不同**——E1 类比 E0 类增益大，这个几乎不可能反
3. **过程质量的提升**——RAG 条件下证据引用准确率肯定更高
4. **错误类型的差异**——无知识时主要是知识缺失错误，有知识时主要是推理错误

这四个保底发现，足以支撑一篇合格的论文。在此基础上，如果知识替代效应、边界效应也成立，就是优秀的论文。

## 七、论文核心论点的"证明地图"

最后，把每个核心论点和对应的证据来源对应起来，方便你写论文时直接查：

| 核心论点 | 主要证据 | 辅助证据 | 在论文中的位置 |
|---------|---------|---------|--------------|
| **RAG 在环评审核中有效** | 整体正确率 K3 > K1，ANOVA 显著 | E1P0/E1P1 分层增益、过程指标提升 | 结果 5.1 主效应分析 |
| **知识替代效应存在** | 交互效应显著，增益 A1 > A2 > A3 | 错误类型：弱模型知识错误多，强模型少 | 结果 5.2 交互效应 |
| **知识替代有边界** | E1P0 上强模型仍有 20%+ 增益 | 地方标准题增益 > 国家标准题 | 结果 5.3 EP 分层分析 |
| **弱模型缺量、强模型缺专** | K2 增益 A3 比 A1 衰减更快；K3 增益衰减较慢 | 过程指标：强模型 K3 引用准确率 >> K2 | 结果 5.2 + 5.4 |
| **任务异质性** | 四类题 RAG 增益排序：E1P0 > E1P1 > E0P1 > E0P0 | 错误类型分布的差异 | 结果 5.3 EP 分层分析 |
| **RAG 提升过程质量** | Faithfulness、证据引用准确率 K3 > K2 > K1 | 推理链完整度对比 | 结果 5.4 过程质量 |
| **增益来自知识内容** | 消融实验：K1 ≈ R0 < K3 | 错误类型从知识型转向推理型 | 结果 5.6 消融实验 |
