# 模型能力操纵检查（二次验证）发现报告 v2.0

> 日期：2026-09-01  
> 题量：15 道高难度校准题（5类×3题）  
> 模型：A1=qwen3.8-flash, A2=qwen3.7-max, A3=qwen3.8-max  
> 条件：K1 闭卷，temperature=0  
> 评分：自动评分 + 人工抽检（A类3题、B类3题、C类1题、D类1题、E类3题，共11题人工确认全对）

---

## 一、核心结论

### ❌ 梯度未成立 — 严重天花板效应

| 模型 | 得分 | 正确率 | 平均延迟 | 平均输出 |
|------|------|--------|---------|---------|
| **A1** (qwen3.8-flash) | 15.0/15 | **100.0%** | 37.8s | 3990 tokens |
| **A2** (qwen3.7-max) | 14.67/15 | **97.8%** | 30.9s | 1989 tokens |
| **A3** (qwen3.8-max) | 15.0/15 | **100.0%** | 86.8s | 3690 tokens |

**三个模型几乎满分，15 道"高难度"校准题完全无法区分能力差异。**

### 关键发现

1. **天花板效应比第一次更严重**：第一次 20 题也是 100%，但以为是题目太简单。这次 15 道"高难度"题还是 100%。
2. **A2 反常垫底**：qwen3.7-max（97.8%）反而不如 qwen3.8-flash（100%）。唯一扣分在 E02 第(3)问的表述差异。
3. **A1 = A3**：flash 版本和 max 版本在这些题目上正确率完全相同。
4. **行为差异存在但正确率无差异**：延迟（37s vs 87s）、输出详细度（A2 最简洁，A1/A3 更啰嗦）有明显差异，但正确率天花板。

## 五、梯度决策（核心）

### 当前状态：❌ 完全无法建立能力梯度

两次操纵检查（20题基础 + 15题高难）都出现天花板效应，三个模型正确率几乎相同。

### 为什么会这样？

1. **Qwen 3.x 系列能力太强**：即使是 flash 版本，在环境工程基础题和一般逻辑推理上已经达到天花板。
2. **题目难度上限**：我们设计的"高难度"题（3-6步推理、多公式组合、冲突识别等）对当前 LLM 来说仍属于"中等难度"。
3. **闭卷条件下知识差异不大**：环境工程基础知识在训练数据中很常见，参数记忆差异不明显。

### 三个可选方案

#### 方案一：换更弱的 A1 模型（推荐指数 ⭐⭐⭐）

- 将 A1 换成更小的模型，比如 qwen2.5-3B / qwen2.5-7B 级别的开源小模型
- 优点：一定能拉开梯度
- 缺点：
  - 小模型可能 API 不可用，需要本地部署
  - 小模型在 RAG 条件下的表现可能完全不可用（读不懂检索结果）
  - 生态位不同，比较意义有限

#### 方案二：放弃"能力梯度"，改为"模型规格/代际差异"研究（推荐指数 ⭐⭐⭐⭐⭐）

- 维持三个模型不变，但重新解释研究问题
- 从"弱-中-强能力梯度"改为 **"轻量版 vs 上一代旗舰 vs 当前旗舰"**
- 研究问题变为：**RAG 对不同规格、不同代际模型的增益是否不同？**
- 优点：
  - 保留所有现有设计和数据
  - 研究问题依然有价值（模型规格与 RAG 增益的关系是真实问题）
  - A2 < A1 的"反常"变成了有趣的发现：新一代轻量模型在某些任务上已超过上一代旗舰
- 缺点：
  - 自变量从"能力"（有序）变成"模型"（类别），统计分析略有不同
  - 需要重新表述假设和理论框架

#### 方案三：大幅提升题目难度到竞赛级（推荐指数 ⭐⭐）

- 设计真正的高难度题：IMO 级数学、奥数级逻辑、非常冷门的专业知识
- 优点：可能拉开差距
- 缺点：
  - 难度大到什么程度能区分？不可预测
  - 题目可能偏离"环境专业"主题，变成纯智力测试
  - 投入产出比低

### 推荐：方案二

**将研究设计从"模型能力梯度"调整为"模型规格差异"**：

- **A1** (qwen3.8-flash) — 轻量快速模型（低延迟、低成本）
- **A2** (qwen3.7-max) — 上一代旗舰模型（前SOTA）
- **A3** (qwen3.8-max) — 当前旗舰模型（现SOTA）

**调整后的研究问题**：外部知识（RAG/搜索）对不同规格 LLM 的环评审核增益是否存在差异？

**调整后的核心假设**：
- H1'：加入领域 RAG 后，三个模型的环评审核正确率均提升
- H2'：RAG 对轻量模型（A1）的增益大于对旗舰模型（A3）的增益（知识替代效应）
- H3'：上一代旗舰（A2）与当前旗舰（A3）的 RAG 增益模式不同（代际差异）

**为什么这个方向更好**：
1. 符合实际情况，不强行建立不存在的梯度
2. 研究问题依然有理论和实践价值
3. "代际差异 + 规格差异"本身就是一个有趣的发现
4. 实验设计几乎不需要改变，只需要重新表述

## 六、对正式实验的影响

如果采用方案二，正式实验的变化：

| 方面 | 原设计（能力梯度） | 新设计（规格差异） |
|------|-------------------|-------------------|
| 自变量名称 | 模型能力（弱/中/强） | 模型规格（轻量/旧旗舰/新旗舰） |
| 变量类型 | 有序 | 类别（3水平） |
| 统计方法 | 有序×有序交互 | 二因素 ANOVA 或 GLMM |

| Pilot 题目 | 不变 | 不变 |
| 实验流程 | 不变 | 不变 |

**几乎所有实验设计都可以沿用，只需要重新表述自变量和假设。**
