# VOCs 产生量、收集量、削减量、排放量总量链条

- **标准编号**：STD-DIFY-15-001
- **知识类型**：formula_chain
- **领域**：总量控制

## 来源依据

  - 广东省工业源VOCs减排量核算方法(2023修订版)；Dify 产污系数与收集效率指南

## 适用范围

用于审核 VOCs 总量控制章节中产生量、收集效率、治理效率、排放量、削减量之间的计算链条。

## 规范性要求

  - VOCs 总量核算应与产污系数、收集效率、治理效率联动一致。
  - 收集效率取值不得高于对应收集方式标准卡上限。
  - 排放量应等于有组织排放量与无组织排放量之和。

## 计算公式

  - name: 收集量；expression: 收集量 = 产生量 × 收集效率
  - name: 未收集量；expression: 未收集量 = 产生量 × (1 - 收集效率)
  - name: 治理后有组织排放量；expression: 有组织排放量 = 收集量 × (1 - 治理效率)
  - name: 总排放量；expression: 总排放量 = 有组织排放量 + 未收集量
  - name: 削减量；expression: 削减量 = 收集量 × 治理效率

## 检查逻辑

  - 调用产污系数标准卡核对产生量。
  - 调用收集效率标准卡核对收集效率。
  - 调用治理设施参数核对治理效率。
  - 重算排放量和削减量。
  - 与报告总量控制指标比对。

  - 无组织排放量
  - 有组织排放量
