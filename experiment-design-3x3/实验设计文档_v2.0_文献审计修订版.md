## 1. 研究背景与问题提出

### 1.1 现实背景

环境影响评价（Environmental Impact Assessment, EIA）是我国环境管理的核心制度之一。环评报告的审核工作具有以下特点：

- **知识密集**：涉及水环境、大气环境、噪声、固体废物等多个领域的排放标准、技术导则和管理规范
- **标准体系复杂**：从国家标准到地方标准、从行业标准到综合排放标准，层级多、数量大
- **合规要求高**：审核结论直接影响项目审批，任何标准引用错误或核算偏差都可能带来环境风险
- **人工成本高**：一份报告的审核需要资深工程师花费数天时间，且高度依赖个人经验

随着大语言模型（LLM）技术的快速发展，利用 AI 辅助环评审核成为行业关注的方向。检索增强生成（Retrieval-Augmented Generation, RAG）被认为是解决 LLM 知识局限性的核心技术路径。

### 1.2 研究现状与 Research Gap

#### 通用 RAG 领域的已有认识

现有研究已经分别证明了三件事：

1. **模型能力会影响检索收益**：随着模型规模增大，RAG 增益呈现递减趋势（Xu et al., 2026; Singh et al., 2026; Ning et al., 2025）。生成器能力还会调节知识选择的作用方式——强模型更受益于召回率，弱模型更受益于精度（Li & Ouyang, 2025）。

2. **检索源/知识质量会影响结果**：RALM 对外部信息质量敏感，检索器不完美或知识源受污染会显著降低鲁棒性（Park & Lee, 2024）。不存在始终最优的单一检索来源（Xu et al., 2026）。

3. **不同任务的收益不同**：任务复杂度、知识依赖度、推理步数都会影响 RAG 的效用（Li & Ouyang, 2025; LaRA, 2025）。

#### 环境/EIA 领域的已有认识

- NEPAQuAD 是首个环境审查 LLM 基准，证明环境监管推理任务具有挑战性，金标上下文时表现最好（Meyur et al., 2025）
- 污染控制指南的 RAG+微调研究证明了领域知识增强在环境专业文本上的有效性（Zhou et al., 2026）
- LLM 辅助 EIA 筛选的研究表明，专业法规判断上仍有局限（Cilliers et al., 2025）

#### Research Gap

> **在专业环境法规审核场景中，模型能力、知识来源与任务特征三者的联合边界尚不清楚。**

现有研究要么只看通用领域，要么只看环境领域但设计简单。尚未发现在真实 EIA/环境法规审核中，同时操纵三档模型能力、三种知识来源条件，并按任务知识-推理需求分层的受控联合检验。

### 1.3 核心科学问题

> **在知识密集型环境专业审核中，外部知识增强的效用如何受到模型能力、知识来源与任务知识—推理需求的共同调节？**

拆解为三个子问题：

**RQ1（参数-非参数知识的替代边界）**
> 在环评法规密集型领域，参数化知识与外部权威知识的替代—互补关系是什么形态？强模型在专业标准知识上是否仍需要 RAG？替代效应的边界在哪里？

**RQ2（知识来源的差异化作用）**
> 不同知识来源条件（无知识 / 联网搜索 / 领域 RAG）对不同能力模型的表现有何差异？领域 RAG 的独有价值体现在哪里？

**RQ3（任务异质性的调节作用）**
> 外部知识的增益在不同类型的审核任务上是否一致？任务的知识依赖度和推理复杂度如何调节 RAG 的效用？

### 1.4 研究意义

**理论意义**：
- 将参数—非参数知识替代关系的研究从通用领域拓展到法规密集型专业领域，检验其领域普适性和边界条件
- 系统揭示模型能力、知识来源与任务类型三者的交互作用机制
- 为理解 RAG 的任务异质性提供新的分析视角（E×P 操作性框架）

**实践意义**：
- 为环评机构的 AI 审核系统选型提供实证依据（用什么模型、配什么知识）
- 为领域 RAG 系统的建设重点提供指导（哪些知识值得入库、哪些可以用搜索替代）
- 为 AI 审核的质量控制提供参考（什么类型的题必须人工复核、什么题可以放心交给 AI）

## 2. 核心概念与理论基础

### 2.1 检索增强生成（RAG）

检索增强生成通过在生成过程中引入外部检索到的知识，来弥补大语言模型的固有局限：
- **幻觉问题**：模型可能生成看似合理但事实错误的内容
- **知识截止**：模型的知识停留在预训练数据的时间点
- **专业知识不足**：通用预训练难以覆盖长尾专业知识

RAG 的核心机制包括：
1. **知识补充**：填补参数化知识的缺口
2. **事实锚定**：将生成锚定在检索到的证据上，减少幻觉
3. **推理脚手架**：提供结构化的领域知识，促进系统化推理

### 2.2 参数—非参数知识的替代—互补关系

**知识替代效应（knowledge substitution effect）**是指：随着模型能力的增强，参数化知识逐渐替代外部检索知识的作用，RAG 的边际收益随之下降。

**现有证据**：
- RAG in the Wild (Xu et al., 2026)：混合知识场景下，检索增益主要局限于较小模型，强模型增益显著下降（事实性 QA 除外）
- To Memorize or to Retrieve (Singh et al., 2026)：小模型从检索中获益最多，大模型收益递减，存在 scaling law
- Less LLM, More Documents (Ning et al., 2025)：存在补偿效应——小模型+大语料可以匹配甚至超过大模型+小语料

**边界与反证**：
- Can Small Language Models Use What They Retrieve? (Pandey, 2026)：7B 以下模型即使有 oracle 检索也有 85-100% 的失败率，存在"利用瓶颈"——这意味着增益曲线可能不是单调递减，而是倒 U 型
- Li & Ouyang (2025)：强模型更受益于召回率（知识量），弱模型更受益于选择精度（知识纯度）——说明"替代"不是简单的一维关系

**本研究的核心追问**：在环评法规领域，参数—非参数知识的替代—互补关系是什么形态？专业法规知识的特殊性是否意味着替代存在边界？

### 2.3 知识来源与质量

知识来源是影响 RAG 效果的重要因素，但不应预设为简单的"质量高低"排序：
- 不同检索来源各有优劣：通用搜索覆盖广但噪声大、时效性强但权威性不一；领域知识库权威但覆盖有限
- 不存在始终最优的单一检索来源（Xu et al., 2026）
- 知识质量应作为操纵检查指标（authoritative-source rate, answer-bearing recall, noise rate, applicability rate），而非实验前预设的自变量等级

### 2.4 任务异质性

RAG 的收益并非均匀分布在所有任务上：
- **知识依赖度**：closed-book vs open-book 是 QA 领域的经典分类（Lewis et al., 2020）
- **推理复杂度**：single-hop vs multi-hop reasoning 是 RAG/QA 领域的常见任务分类
- Li & Ouyang (2025) 明确指出任务复杂度影响知识选择对 RAG 的作用

但现有研究对任务异质性的讨论多停留在描述层面，缺乏统一的分类框架和系统的实证检验。

## 3. 研究假设与探索性问题

> **说明**：以下 H1-H5 为正式研究假设（有文献方向性支持，可证伪）；RQ-探索性问题为数据驱动的探索（文献不足以给出方向性预判，在结果中报告发现）。

### 3.1 主效应假设

**H1（RAG 有效性假设）**：领域 RAG 条件下的环评审核正确率显著高于无外部知识条件。
- 检验方式：知识来源主效应（混合效应逻辑回归），K3 vs K1 对比
- 依据：RAG 领域共识 + 环境领域 Zhou et al. (2026) 直接证据
- 支持强度：⭐⭐⭐ Strong

**H2（模型能力假设）**：强模型的环评审核正确率显著高于弱模型。
- 检验方式：模型能力主效应，A3 vs A1 对比
- 依据：LLM scaling law 共识
- 支持强度：⭐⭐⭐ Strong

### 3.2 交互效应假设

**H3（知识替代假设）**：外部知识的增益因模型能力而异——弱模型的知识增益显著大于强模型（方向性预期：增益递减，但不预设严格单调）。
- 检验方式：模型能力 × 知识来源交互效应，简单效应分析
- 依据：RAG in the Wild (Xu et al., 2026)、To Memorize or to Retrieve (Singh et al., 2026)、Less LLM More Documents (Ning et al., 2025)
- 支持强度：⭐⭐ Medium-Strong（通用领域有充分证据，环评领域待检验）
- ⚠️ 注意：不预设严格单调递减——小模型端可能存在利用瓶颈（Pandey, 2026），A1 增益可能反而低于 A2

**H4（知识来源差异化假设）**：不同知识来源条件对不同能力模型的影响不同。
- 检验方式：简单效应分析，对比各模型上 K2-K1 和 K3-K1 的差值模式
- 依据：Li & Ouyang (2025) 发现模型能力调节知识选择的作用
- 支持强度：⭐⭐ Medium
- ⚠️ 注意：**"强模型对知识质量更敏感"不作为假设**，而是探索性问题（见 EQ1）

### 3.3 边界与异质性假设

**H5（不可替代性假设）**：即使是强模型，在外部知识依赖型任务（E1 类）上，领域 RAG 仍能带来显著提升。
- 检验方式：强模型在 E1 类题上的 K3 vs K1 对比
- 依据：方向合理——环评专业法规知识是长尾知识，强模型的预训练可能覆盖不足
- 支持强度：⭐⭐ Medium（环境领域无直接证据，需实证检验）

**H6（任务异质性假设）**：外部知识的效应因任务的知识依赖度和推理复杂度而异。
- 检验方式：E 维度 × 知识来源、P 维度 × 知识来源的交互效应
- 依据：任务异质性共识 + Li & Ouyang (2025)
- 支持强度：⭐⭐ Medium
- ⚠️ 注意：**不设固定四格排序**。E1P0 > E1P1 > E0P1 > E0P0 是方向性推测，不是预注册假设

### 3.4 过程质量假设

**H7（过程质量假设）**：领域 RAG 不仅提升结论正确率，还提升答案的过程质量（证据忠实度、引用准确率、推理完整性）。
- 检验方式：过程指标的知识来源主效应
- 依据：RAG 忠实度相关文献
- 支持强度：⭐⭐ Medium

### 3.5 探索性问题（Exploratory Questions）

> 以下问题没有足够的文献基础给出方向性预判，将在实验结果中做数据驱动的探索分析。

**EQ1：知识来源的作用模式是什么？**
> 弱模型和强模型分别更受益于"知识量"还是"知识专精度"？K2（通用搜索）和 K3（领域 RAG）的增益比在不同模型上有何差异？

**EQ2：增益曲线的形态是什么？**
> RAG 增益随模型能力的变化是单调递减，还是倒 U 型？弱模型是否存在"利用瓶颈"？

**EQ3：E×P 四格的增益排序是什么？**
> 四类任务的 RAG 增益具体排序如何？是否存在"P1 类题因多跳/干扰导致收益下降"的现象？

**EQ4：错误类型的迁移模式是什么？**
> RAG 如何改变错误类型的分布？是减少了知识错误还是引入了新的错误类型？

## 4. 3×3 析因实验设计

### 4.1 设计概述

本研究采用 **3（模型能力：弱/中/强）× 3（知识来源条件：无知识/联网搜索/领域 RAG）** 的析因设计。

每道题在 9 种条件下各运行一次，形成嵌套结构（题目嵌套在 EP 类别中，回答嵌套在题目中）。

```
                    模型能力（Ability, A）
           ┌──────────┬──────────┬──────────┐
           │  A1 弱    │  A2 中    │  A3 强    │
        ┌──┼──────────┼──────────┼──────────┤
        │K1│  K1A1    │  K1A2    │  K1A3    │
知识条件  │  │  无知识   │  无知识   │  无知识   │
（Knowledge│  │  基线     │          │  天花板   │
Condition├──┼──────────┼──────────┼──────────┤
  K）   │K2│  K2A1    │  K2A2    │  K2A3    │
        │  │  搜索     │  搜索     │  搜索     │
        │  │  开放式   │          │  开放式   │
        ├──┼──────────┼──────────┼──────────┤
        │K3│  K3A1    │  K3A2    │  K3A3    │
        │  │  领域RAG  │  领域RAG  │  领域RAG  │
        │  │  权威式   │          │  权威式   │
        └──┴──────────┴──────────┴──────────┘
```

### 4.2 自变量 A：模型能力（3 水平）

| 水平 | 代号 | 拟选模型 | 说明 |
|------|------|---------|------|
| 弱 | A1 | qwen3.8-flash | 入门级轻量模型 |
| 中 | A2 | qwen3.7-max | 上一代旗舰模型 |
| 强 | A3 | qwen3.8-max | 当前旗舰模型 |

**选择逻辑**：都是 Qwen 同系列，训练数据和架构相近。用"上代旗舰"做中间档，能力梯度比"同代 plus"更大。

> ⚠️ **操纵检查要求（必须做）**：
> - 不能只靠产品名宣布"弱/中/强"
> - 正式实验前需在**独立校准集**（K1 无知识 + 通用非领域任务）上验证 A1 < A2 < A3 是否大体成立
> - 如果不成立，调整模型选择或重新命名水平

**为什么需要操纵检查**：不同代际 Qwen 的差异不仅是"能力"，还可能包括训练数据、post-training、context handling、instruction following 等。需要确认能力维度是主要差异来源。

### 4.3 自变量 K：知识来源条件（3 水平）

| 水平 | 代号 | 实现方式 | 说明 |
|------|------|---------|------|
| 无知识 | K1 | 纯模型 + 报告内容 | 基线，模型只能靠内置参数知识 |
| 联网搜索 | K2 | Serper.dev API，top-5 结果 | 开放式网络知识，模拟"用搜索引擎查资料" |
| 领域 RAG | K3 | 81 源环评专业知识库，混合检索 | 领域结构化知识，模拟"查专业法规手册" |

> ⚠️ **重要说明**：
> - K1/K2/K3 是**三种知识来源类别（categorical variable）**，不是严格的"质量高低"有序变量
> - 联网搜索可能在某些题上比封闭领域库更好（比如时效性强的问题），这本身就是有效结果
> - 知识质量是**操纵检查指标**，不是自变量等级：后续会测量 authoritative-source rate、answer-bearing recall、noise rate、applicability rate

### 4.4 调节变量：E×P 任务类型

E（知识依赖度）和 P（推理复杂度）是任务层面的分类变量，用于分层分析和交互检验。详见第 5 章。

### 4.5 因变量

**主要因变量**：结论正确率（二元：CORRECT/INCORRECT）

**次要因变量**：过程指标（见第 6 章）

### 4.6 控制变量与混淆变量处理

| 变量 | 处理方式 | 说明 |
|------|---------|------|
| 提示词模板 | 固定模板，仅替换知识部分 | 所有条件使用相同系统提示词结构 |
| 生成参数 | temperature=0, max_tokens=8192 | 统一设置 |
| 题目顺序 | 所有条件一致 | 避免顺序效应 |
| 输入长度 / token 数 | **记录并控制** | K1/K2/K3 输入长度明显不同，是关键混淆变量 |
| 检索结果 token 预算 | **尽量控制 Top-N 证据总 token 数接近** | 不只是"都是 Top-5" |
| 检索结果数量 | 记录 evidence count、answer-bearing evidence count | 作为协变量 |
| 重复次数 | 1 次（temperature=0，无随机性） | 无需多次取平均 |

> ⚠️ **重点混淆变量：上下文长度**
> K1 只有报告内容，K2/K3 额外增加了检索结果，输入长度不同。这可能导致：
> - 长上下文本身的推理能力变化（注意力稀释等）
> - 格式效应（多了"参考资料"结构）
> - 应记录 input tokens / retrieved tokens，并在分析中考虑其影响
> - 可选：增加 R0 组（等量长度但无意义文本）作为长度对照，但成本较高，pilot 后决定是否加

## 5. E×P 任务分类框架

### 5.1 框架定位

> **AUTHOR_PROPOSED_OPERATIONAL_FRAMEWORK**
>
> E×P 是本文提出的**操作性任务分类框架**，不是成熟理论。E 和 P 两个维度各有文献传统，但 2×2 组合是本文的工作。

框架的价值在于提供系统的任务异质性分析工具，而非理论创新。

### 5.2 E 维度：外部知识依赖度（External Knowledge Dependency）

**判定规则**：金标准结论是否需要报告之外的权威知识才能独立得到。

| 类别 | 代号 | 判定规则 | 典型任务 |
|------|------|---------|---------|
| 报告内知识 | E0 | 报告内容本身足以确定 Gold 结论 | 从报告中提取数据、核对报告内数据一致性、复算报告内已有的计算 |
| 外部知识 | E1 | 缺少外部法规/标准/名录/技术依据时，Gold 不能可靠确定 | 判断排放是否达标、识别危废类别、评价废气收集效率是否合理 |

**文献基础**：
- Lewis et al. (2020)：knowledge-intensive NLP tasks 与外部非参数知识
- DomainRAG：closed-book 模型在领域特定问题上的困难
- NEPAQuAD：环境审查的 with-context / no-context 比较

### 5.3 P 维度：推理复杂度（Reasoning/Processing Complexity）

**判定规则**：得出答案需要的认知操作步数和整合复杂度。

| 类别 | 代号 | 判定规则 | 典型任务 |
|------|------|---------|---------|
| 单步/直接映射 | P0 | 单步定位或直接规则映射，答案可以直接从文本中找到 | 提取某个数据、判断某个标准限值是多少、简单的达标判断 |
| 多步/综合判断 | P1 | 需要至少两步以上的计算、条件组合、跨证据整合或规则适用性判断 | 复算排放量、判断收集效率是否合理、危废类别的综合识别 |

**文献基础**：
- MultiHop-RAG：跨多份证据的 multi-hop query
- Li & Ouyang (2025)：task/dataset complexity 调节 knowledge selection
- LaRA (2025)：最优知识策略随 task type 和模型能力变化

> ⚠️ 注意：P 维度不只是"要不要算数"。计算只是多步推理的一种形式，还有条件判断、跨证据整合、规则适用性判断等。

### 5.4 四类任务详解

| 类别 | 全称 | 特点 | RAG 作用的预期 |
|------|------|------|--------------|
| **E0P0** | 报告内 + 单步 | 答案就在报告里，直接找就行 | 增益最小：知识已经在报告里了，主要靠阅读理解 |
| **E0P1** | 报告内 + 多步 | 数据都在报告里，但需要计算/比对/推理 | 增益较小：主要靠计算和推理能力，RAG 可能提供方法参考 |
| **E1P0** | 外部知识 + 单步 | 答案在外部法规里，查到就能答对 | 增益最大：纯模型靠内置知识答不准，RAG 一查就有 |
| **E1P1** | 外部知识 + 多步 | 既需要外部知识，又需要推理计算 | 增益中等：知识有帮助，但不是全部——还要会用知识做推理 |

### 5.5 分类的预期规律（方向性，不是强假设）

| 规律 | 内容 | 依据 |
|------|------|------|
| E 维度影响知识增益大小 | E1 类增益 > E0 类增益 | E0 类知识已经在报告里，RAG 补充空间有限 |
| P 维度影响模型差异幅度 | P1 类模型差异 > P0 类模型差异 | P1 需要推理能力，强模型的推理优势更明显 |
| P 维度可能影响知识利用效率 | 方向不确定——复杂任务既可能更需要检索，也可能因为多跳/干扰导致收益下降 | Li & Ouyang (2025)、multi-hop RAG 文献 |

> 不预注册固定的四格排序。具体排序是探索性问题 EQ3。

## 6. 评价指标体系

### 6.1 三层指标架构

```
第一层：结论准确率（核心指标）
    ↓
第二层：过程指标（诊断指标，按EP分类差异化）
    ↓
第三层：错误类型分析（深度诊断）
```

### 6.2 第一层：结论准确率

**定义**：模型最终判断（CORRECT / INCORRECT）与金标准一致的题目比例。

**特点**：
- 客观、无争议
- 是论文的核心结果指标
- 二元变量，使用混合效应逻辑回归分析

### 6.3 第二层：过程指标（按 EP 差异化设计）

过程指标用于诊断"对在哪里、错在哪里"。

#### E0P0（字段抽取类）过程指标

| 指标 | 说明 |
|------|------|
| 章节定位准确率 | 是否找到了正确的章节/位置 |
| 数据提取准确率 | 提取的数值是否准确 |

#### E1P0（标准查阅类）过程指标

| 指标 | 说明 |
|------|------|
| 标准引用准确率 | 引用的标准名称、编号是否正确 |
| 数值准确率 | 查到的限值/代码等数值是否准确 |

#### E0P1（一致性复算类）过程指标

| 指标 | 说明 |
|------|------|
| 参数提取准确率 | 从报告中提取的原始参数是否正确 |
| 公式/方法正确率 | 使用的计算公式/方法是否正确 |
| 计算结果准确率 | 最终计算结果是否正确 |

#### E1P1（综合推理类）过程指标

| 指标 | 说明 |
|------|------|
| 场景识别准确率 | 是否正确识别了审核场景和适用标准 |
| 知识引用准确率 | 引用的知识/标准是否正确 |
| 推理完整性 | 推理链条是否完整、逻辑是否自洽 |
| 最终判断准确率 | 最终结论是否正确 |

### 6.4 第三层：错误类型分析

#### 按错误方向分

| 错误类型 | 定义 |
|---------|------|
| **假阳性（FP）** | 金标准 CORRECT，模型判 INCORRECT |
| **假阴性（FN）** | 金标准 INCORRECT，模型判 CORRECT |

**衍生指标**：精确率（Precision）、召回率（Recall）、F1 值、假阳性率、假阴性率

> **环评审核场景判断**：假阴性（漏检错误）比假阳性（过度审核）后果更严重。

#### 按错误环节分

| 错误类型 | 定义 | 对应 EP 类 |
|---------|------|-----------|
| 提取错误 | 数据/信息从源文本中提取错了 | E0 类为主 |
| 计算错误 | 公式用对了但数算错了 | P1 类为主 |
| 知识错误 | 引用的标准/知识本身不对 | E1 类为主 |
| 推理错误 | 知识对了但推理/判断逻辑错了 | P1 类为主 |
| 方法错误 | 用了错误的计算/判断方法 | E1P1 为主 |

#### 幻觉检测

| 幻觉类型 | 定义 | 出现场景 |
|---------|------|---------|
| 编造标准 | 引用了不存在的标准名称或编号 | E1 类，K1 条件下最多 |
| 编造数据 | 报告/标准里没有的数据，模型自己编的 | E0、E1 均可能 |
| 编造章节 | 声称"见报告第X章"但实际没有 | E0 类 |

### 6.5 知识质量操纵检查指标

| 指标 | 说明 |
|------|------|
| authoritative-source rate | 检索结果中权威来源（国家标准、行业导则等）的比例 |
| answer-bearing recall | 检索结果中包含答案所需关键信息的比例 |
| noise rate | 检索结果中无关/干扰内容的比例 |
| applicability rate | 检索结果与本题审核场景的适用程度 |

这些指标用于解释 K2 和 K3 效果差异的机制。

## 7. 统计分析方法

### 7.1 方法选择依据

> **不能只用双因素 ANOVA**，原因：
> 1. 结论正确率是**二元数据**（0/1），不满足 ANOVA 的正态性假设
> 2. 同一道题在 9 个条件下重复出现，360 条回答**不独立**（题目是随机效应）
> 3. 可能存在项目（报告）层面的聚类效应

### 7.2 主分析：混合效应逻辑回归

**模型形式**：

```
Correct ~ Model + Knowledge + Model×Knowledge + E + P + KeyInteractions + (1 | question) + (1 | project)
```

**固定效应**：
- Model（A1/A2/A3）
- Knowledge（K1/K2/K3）
- Model × Knowledge（核心交互，检验 H3）
- E（E0/E1）
- P（P0/P1）
- 关键交互：Knowledge × E, Knowledge × P, Model × E, Model × P（逐步选择，看是否纳入）

**随机效应**：
- (1 | question)：题目随机截距
- (1 | project)：报告/项目随机截距（如果多道题来自同一报告）

**估计方法**：最大似然估计（ML），使用 lme4/glmmTMB 等包

### 7.3 辅助分析

1. **描述性统计**：各条件下的正确率、95% 置信区间（用二项分布精确法或 bootstrap）
2. **ANOVA 作为描述性补充**：可作为直观展示，但不宜作为唯一主分析
3. **事后对比**：
   - 知识来源：K3 vs K1, K2 vs K1, K3 vs K2（用模型的对比检验，Tukey 校正）
   - 模型能力：A3 vs A1, A2 vs A1, A3 vs A2
4. **简单效应分析**：交互效应显著时，分析各模型水平上的知识来源效应
5. **EP 分层分析**：按 EP 类别分别拟合模型，检验任务异质性
6. **过程指标分析**：连续过程指标使用线性混合模型（LMM），二元过程指标使用 GLMM

### 7.4 效应量报告

- 主要效应报告 **OR（比值比）** 和 95% CI
- 模型间差异报告 **风险差（Risk Difference）** 和 95% CI
- 交互效应报告 **交互项系数** 和 p 值
- 不只用 p 值，重点报告效应大小和置信区间

### 7.5 样本量与统计效力

**现状**：40 题（每 EP 10 题）对于三维交互检验偏紧。

**规划**：
- **Pilot（16 题）**：只检查可行性、操纵是否生效、估计效应大小和方差
- **基于 pilot 的效力分析**：用 pilot 数据估计效应后做 simulation-based power analysis
- **正式实验目标**：优先争取 **60-80 题（每 EP 15-20 题）**
- **如果只能 40 题**：减少高阶交互和假设数量，聚焦核心的 Model × Knowledge 二维交互，避免"7 个假设 + 大量分层"

## 8. 预期结果与创新点

### 8.1 预期的方向性结果

> 以下为方向性预期，用于实验设计参考，不是预注册的假设。

**预期的 3×3 正确率趋势**：

| | A1 弱模型 | A2 中模型 | A3 强模型 |
|---|---|---|---|
| K1 无知识 | 最低 | 中等 | 最高 |
| K2 联网搜索 | 提升明显 | 提升中等 | 提升较小 |
| K3 领域 RAG | 提升最大 | 提升较大 | 提升中等 |

**预期的 EP 分层趋势（强模型上）**：
- E1P0：RAG 增益最大（知识依赖高，推理简单）
- E1P1：RAG 增益中等偏大（知识依赖高，但推理复杂）
- E0P1：RAG 增益较小（知识依赖低，推理靠能力）
- E0P0：RAG 增益最小（知识就在报告里）

### 8.2 核心创新点（按强度排序）

#### I1：专业法规领域中参数—非参数知识的替代—互补边界

> 在环评法规密集型场景中系统检验参数化知识与外部权威知识的替代—互补关系，揭示专业长尾知识中替代效应的边界条件——拓展了 RAG scaling 理论的领域特异性。

**地位**：⭐⭐⭐ 最强创新点，理论意义最大
**核心证据**：强模型在 E1 类任务上的 RAG 增益大小 + 增益曲线形态
**理论钩子**：parametric knowledge 与 non-parametric knowledge 在专业法规长尾知识环境中的替代—互补边界

#### I2：不同知识来源对不同能力模型的差异化作用（需等数据）

> 系统比较无知识、开放式搜索、权威领域 RAG 三种知识条件在不同能力模型上的作用模式，揭示"弱模型与强模型分别需要什么类型的知识"——为 RAG 系统的分层建设策略提供实证依据。

**地位**：⭐⭐ 中等强度，必须等数据才能确立
**注意**：**实验前不要写"弱模型缺量、强模型缺专"作为结论**，这是需要数据验证的预测
**核心证据**：各模型上 K2-K1 / K3-K1 的增益比

#### I3：E×P 操作性分类框架与任务异质性分析

> 提出"外部知识依赖度 × 推理复杂度"的二维操作性分类框架，系统分析环评审核任务的异质性规律——为理解 RAG 在不同专业审核任务上的效用差异提供分析工具。

**地位**：⭐ 方法贡献，不是理论创新
**定位**：E×P 是 operational taxonomy，而非新理论
**价值**：实用价值（任务难度分层、系统设计参考）+ 分析价值（定位增益来源）

### 8.3 论文的理论提升方向

论文真正的理论贡献不是"做了 3×3"，也不是"提出了 E×P"，而是：

> **在专业法规长尾知识环境中，揭示 parametric knowledge 与 authoritative external knowledge 的替代—互补边界。**

三维设计和 E×P 框架都是识别这个边界的工具。

## 9. 实验设置与实施流程

### 9.1 评价集

| 阶段 | 题量 | EP 分布 | 用途 |
|------|------|---------|------|
| Pilot | 16 题 | 每类 4 题 | 可行性检验、操纵检查、效应估计、效力计算 |
| 正式（目标） | 60-80 题 | 每类 15-20 题 | 主分析、假设检验 |
| 正式（下限） | 40 题 | 每类 10 题 | 聚焦核心交互，减少高阶假设 |

- **题目来源**：基于真实环评报告构造，每道题附有金标准答案和核验依据
- **金标准质量**：每道题经过原始报告核验，结论非黑即白
- **题目格式**：核心判断为 CORRECT / INCORRECT 二元，附推理过程

### 9.2 模型能力操纵检查（必须做，在 pilot 前）

**目的**：验证 A1 < A2 < A3 的能力梯度确实存在。

**方法**：
- 选用一组**通用非领域**的知识+推理题（与环评无关）
- 在 K1 无知识条件下运行三个模型
- 检验正确率是否满足 A1 < A2 < A3
- 如果不满足，调整模型选择

### 9.3 实验条件

| 维度 | 参数 | 值 |
|------|------|----|
| 模型 A1 | 弱模型 | qwen3.8-flash（待操纵检查确认梯度） |
| 模型 A2 | 中模型 | qwen3.7-max（待操纵检查确认梯度） |
| 模型 A3 | 强模型 | qwen3.8-max（待操纵检查确认梯度） |
| 生成参数 | temperature | 0（无随机性，仅需运行 1 次） |
| 生成参数 | max_tokens | 8192 |
| K2 实现 | 搜索 API | Serper.dev，top-5 结果 |
| K3 实现 | 领域 RAG | 81 源环评知识库，BM25 + 稠密向量混合检索 |
| 输出格式 | JSON | conclusion + reasoning + evidence |

### 9.4 实施流程

```
第 0 步：实验前准备（2 天）
  ├─ 模型能力操纵检查（验证 A1<A2<A3）
  ├─ 确认三个模型 ID 和 API 可用性
  ├─ 确认 K2 联网搜索实现方案
  ├─ 确认 K3 领域 RAG 知识库配置
  └─ 冻结 pilot 评价集 16 题

第 1 步：Pilot 实验（1-2 天）
  ├─ 运行 9 条件 × 16 题 = 144 次调用
  ├─ 验证输出格式和评分逻辑
  ├─ 调试 prompt 和参数
  └─ 记录输入 token 数、检索质量等操纵检查指标

第 2 步：Pilot 分析与效力计算（1-2 天）
  ├─ 初步检查核心趋势是否存在
  ├─ 估计效应大小和方差
  ├─ Simulation-based power analysis
  └─ 确定正式实验题量（40 / 60 / 80）

第 3 步：正式评价集扩充与冻结（2-3 天）
  ├─ 按 EP 均衡扩充题目
  ├─ 金标准人工核验
  └─ 冻结正式评价集

第 4 步：正式实验（3-7 天，视题量而定）
  ├─ K1 组：无知识基线
  ├─ K2 组：联网搜索
  └─ K3 组：领域 RAG

第 5 步：评分与分析（3-5 天）
  ├─ 自动评分 + 人工抽样核验
  ├─ 混合效应模型分析
  ├─ EP 分层分析
  ├─ 错误类型标注与分析
  └─ 知识质量操纵检查分析
```

### 9.5 质量控制

1. **金标准质量**：每道题的金标准答案均经过原始报告核验，确保准确无误
2. **评分一致性**：自动评分逻辑经过人工抽样核验，一致率 ≥ 95%
3. **模型梯度验证**：实验前用独立校准集验证模型能力梯度
4. **知识质量操纵检查**：记录并分析 K2/K3 的知识质量指标
5. **混淆变量记录**：输入 token 数、检索结果数等完整记录
6. **实验可复现**：所有 prompt、参数、模型版本、知识库版本、检索配置均完整记录

### 9.6 旧实验数据的定位

之前的 ABCD 四组（Skill+RAG）实验：
- **定位**：preliminary method-development experiment（前期方法开发实验）
- **作用**：解释为什么正式研究去掉 Skill、纯化 Knowledge 变量
- **正文中的位置**：研究背景/方法部分一句交代
- **详细结果**：放补充材料或不放入主论文
- **不要做的**：不要放进正式主结果与新 3×3 合并比较

| 广义线性混合模型 | Generalized Linear Mixed Model, GLMM | 适用于非正态因变量（如二元数据）的混合效应模型 |
| 操纵检查 | manipulation check | 验证实验操纵是否按预期生效的检查 |
| 假阳性 | False Positive, FP | 金标准为正确但模型判为错误 |
| 假阴性 | False Negative, FN | 金标准为错误但模型判为正确 |
