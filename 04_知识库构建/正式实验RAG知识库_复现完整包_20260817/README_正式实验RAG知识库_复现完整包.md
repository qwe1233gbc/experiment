# 正式实验RAG知识库复现完整包

本包对应2026-08-12冻结的正式A/B/C/D实验，其中B组和D组使用相同的RAG证据。

## 正式口径

- 知识库：70项知识源（52源基础库加18项P0/P1官方证据）。
- RAG索引：398个父块、3433个子块。
- 检索流程：Dense与BM25经RRF融合，进行标准号和行业代码精确加权，随后使用`gte-rerank-v2`重排、来源去重并扩展父块。
- 嵌入模型：`text-embedding-v4`，1024维。
- 实验输入：21道正式评价题，每题冻结Top-5上下文，B/D组共用。
- 冻结RAG文件SHA-256：`fc3cc897cc99d2fb32deb6f68c75cf8a410da7b7a33f57ad0edba4eac02e1dd1`。

## 目录说明

- `01_正式知识源_70文件`：正式实验增强知识库的70项全文或结构化知识文件。
- `02_RAG分块向量与检索索引`：父子分块、3433条向量、BM25与混合检索索引及配置登记。
- `03_按问题类型分类_21题`：按7类审核问题整理的核心依据文件和正式实验Top-5实际命中文件。
- `04_冻结RAG上下文_21题`：B/D组真正输入模型的21题固定Top-5上下文、逐题哈希及验收报告。
- `05_清单与来源追踪`：知识源来源、版本关系、检索冒烟测试、正式评价集及Source of Truth。
- `文件SHA256清单.csv`：包内文件的SHA-256验收清单，不包含该清单自身。

## 使用边界

- 本包是正式文件的只读复制与打包，未移动或修改原始冻结知识库。
- 待审核环评报告JSON不属于法规RAG知识库，未纳入本包。
- Skill属于程序性审核约束，不属于RAG知识文件，未纳入本包。
- `03_按问题类型分类_21题`中的“核心答案依据”和“实验Top-5实际命中”是两种不同口径：前者为人工冻结的预期证据，后者为检索算法实际送入模型的来源。
- 52源基础库中的source ID与70源增强库重新编号后的source ID不能直接等同，应结合文件名和冻结清单解析。
