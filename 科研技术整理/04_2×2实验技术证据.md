## 1. 为什么是2×2析因设计

单一"系统 vs 基线"的对比只能回答"有没有用"，无法回答"哪部分有用、是否冲突"。2×2析因把两个增强因子正交：

```
                Skill=0              Skill=1
RAG=0     A：纯LLM基线        C：LLM+Skill（程序约束）
RAG=1     B：LLM+RAG（知识约束）  D：LLM+RAG+Skill（双约束）
```

| 科学问题 | 由哪个对比回答 |
|---|---|
| RAG的独立贡献 | RAG主效应 + 简单效应 B−A |
| Skill的独立贡献 | Skill主效应 + 简单效应 C−A |
| RAG×Skill的协同/干扰 | 交互效应（D−C−B+A）及三种等价算法 |
| 联合系统是否超越基线 | D−A |

每道题在四个条件下各回答一次（**题内配对**，question为区组单位），48题×4=192条观测——这是配对析因，统计功效高于独立组设计。

## 6. 最终结果速览（详见03号文档）

| 组 | mean (common_3d_percent) | 满分占比 |
|---|---|---|
| A（LLM） | 93.06 | 66.7% |
| B（+RAG） | 91.67 | 60.4% |
| C（+Skill） | 86.11 | 41.7% |
| D（+RAG+Skill） | 91.32 | 56.3% |

三效应：RAG main +0.115（不显著）；Skill main −0.219（显著负）；**Interaction +0.396（显著正，补偿型）**。机制判定同时满足"正向交互"与"任务依赖性"（知识核验型任务驱动，V01类负交互）。

**已知局限**（statistical_report.md §10，展览引用结果时应一并说明）：
1. 天花板效应（A组66.7%满分、evidence_use几乎无变异），效应幅度可能被低估；
2. LLM单裁判盲评，未与人工专家盲评交叉验证；
3. 14类中9类n≤3，类别内效应仅作模式观察；
4. SourceStrength题型全部剔除，结论不外推；
5. 结论限于LLM-judge共同三维评分框架。

## 7. 面向展览的2×2一句话表达

> 用48道真实环评审核题、每题在"纯模型 / +RAG / +Skill / +RAG+Skill"四个条件下各审一遍（共192份匿名回答、人工确认的Gold标准、防泄漏的冻结证据快照），2×2析因统计给出可分离的因果证据：RAG的独立贡献不显著、Skill单独使用显著降低表现、而二者组合产生统计显著的正向交互（+0.396，95% CI [0.167, 0.625]）——证明专业审核能力=知识约束×程序约束的乘积，而不是单一技术的叠加。
