## 1. 研究背景与问题提出

### 1.1 现实背景

环境影响评价（Environmental Impact Assessment, EIA）是我国环境管理的核心制度之一。环评报告的审核工作具有以下特点：

- **知识密集**：涉及水环境、大气环境、噪声、固体废物等多个领域的排放标准、技术导则和管理规范
- **标准体系复杂**：从国家标准到地方标准、从行业标准到综合排放标准，层级多、数量大
- **合规要求高**：审核结论直接影响项目审批，任何标准引用错误或核算偏差都可能带来环境风险
- **人工成本高**：一份报告的审核需要资深工程师花费数天时间，且高度依赖个人经验

随着大语言模型（LLM）技术的快速发展，利用 AI 辅助环评审核成为行业关注的方向。检索增强生成（Retrieval-Augmented Generation, RAG）被认为是解决 LLM 知识局限性的核心技术路径。然而，以下关键问题尚未得到系统回答：

### 1.2 研究问题

围绕"环评审核场景下，模型能力与外部知识如何共同影响审核表现"这一核心问题，本研究聚焦三个子问题：

**RQ1：知识替代效应的边界问题**
> 在环评法规密集型领域，知识替代效应是否仍然成立？强模型在专业标准知识上是否仍需要 RAG？如果存在边界，边界在哪里？

**RQ2：知识质量的调节作用问题**
> 不同质量的知识来源（无知识 / 联网搜索 / 领域 RAG）对不同能力模型的表现有何差异？领域 RAG 的独有价值体现在哪里？

**RQ3：任务异质性问题**
> RAG 的增益在不同类型的审核任务上是否一致？什么类型的任务受益最大？什么类型的任务受益最小？任务的哪些特征决定了 RAG 的效用？

### 1.3 研究意义

**理论意义**：
- 将知识替代效应的研究从通用领域拓展到法规密集型专业领域，检验其领域普适性
- 提出"知识依赖度 × 推理复杂度"的任务分类框架，为理解 RAG 任务异质性提供新的分析视角
- 系统揭示模型能力、知识质量与任务类型三者的交互作用机制

**实践意义**：
- 为环评机构的 AI 审核系统选型提供实证依据（用什么模型、配什么知识）
- 为领域 RAG 系统的建设重点提供指导（哪些知识值得入库、哪些可以用搜索替代）
- 为 AI 审核的质量控制提供参考（什么类型的题必须人工复核、什么题可以放心交给 AI）

## 2. 核心概念与理论基础

### 2.1 检索增强生成（RAG）

检索增强生成通过在生成过程中引入外部检索到的知识，来弥补大语言模型的固有局限：
- **幻觉问题**：模型可能生成看似合理但事实错误的内容
- **知识截止**：模型的知识停留在预训练数据的时间点
- **专业知识不足**：通用预训练难以覆盖长尾专业知识

RAG 的核心机制包括：
1. **知识补充**：填补参数化知识的缺口
2. **事实锚定**：将生成锚定在检索到的证据上，减少幻觉
3. **推理脚手架**：提供结构化的领域知识，促进系统化推理

### 2.2 知识替代效应

知识替代效应（knowledge substitution effect）是指：随着模型能力的增强，参数化知识逐渐替代外部检索知识的作用，RAG 的边际收益随之下降。

现有研究（RAG in the Wild, ACL 2026; To Memorize or to Retrieve, 2026）表明：
- 在通用知识领域，强模型的 RAG 增益显著低于弱模型
- 增益的下降幅度与任务类型有关，事实性任务上 RAG 仍保持一定价值
- 预训练饱和程度是影响替代效应的关键因素

**本研究的核心追问**：在环评法规领域，知识替代效应是否仍然成立？专业法规知识的特殊性是否意味着替代存在边界？

### 2.3 任务异质性

RAG 的收益并非均匀分布在所有任务上。任务的以下特征会影响 RAG 的效用：
- **知识依赖度**：任务需要的知识有多少在模型参数内、有多少需要外部获取
- **推理复杂度**：任务是简单的信息提取，还是需要多步推理和计算
- **领域专业性**：任务涉及的知识是通用常识还是专业领域知识

现有研究对任务异质性的讨论多停留在描述层面，缺乏系统的分类框架和实证检验。

## 3. 研究假设

基于上述研究问题和理论基础，本研究提出以下 7 个假设：

### 3.1 主效应假设

**H1（RAG 有效性假设）**：领域 RAG 条件下的环评审核正确率显著高于无外部知识条件。
- 检验方式：知识来源主效应（ANOVA），K3 vs K1 事后比较
- 通过标准：整体正确率增益 ≥ 15%，p < 0.05

**H2（模型能力假设）**：强模型的环评审核正确率显著高于弱模型。
- 检验方式：模型能力主效应（ANOVA），A3 vs A1 事后比较
- 通过标准：强模型比弱模型高 ≥ 20%，p < 0.05

### 3.2 交互效应假设

**H3（知识替代假设）**：RAG 增益随模型能力提升而递减，弱模型的 RAG 增益显著大于强模型。
- 检验方式：模型能力 × 知识来源交互效应（ANOVA），简单效应分析
- 通过标准：A1 增益 - A3 增益 ≥ 10 个百分点，交互效应显著

**H4（知识质量调节假设）**：知识质量的增益效果因模型能力而异——弱模型从任何知识中都能受益，强模型更多受益于高质量领域知识。
- 检验方式：简单效应分析，对比各模型上 K2-K1 和 K3-K2 的差值
- 通过标准：A1 上 K2 增益 / K3 增益 > 0.7；A3 上 K2 增益 / K3 增益 < 0.4

### 3.3 边界与异质性假设

**H5（不可替代性假设）**：即使是强模型，在外部知识依赖型任务（E1 类）上，领域 RAG 仍能带来显著提升。
- 检验方式：强模型在 E1 类题上的 K3 vs K1 对比
- 通过标准：E1P0 增益 ≥ 20%，E1P1 增益 ≥ 15%

**H6（任务异质性假设）**：RAG 增益按以下顺序递减：E1P0 > E1P1 > E0P1 > E0P0。
- 检验方式：EP 类型 × 知识来源的交互效应
- 通过标准：E1 类增益显著大于 E0 类，P0 类增益显著大于 P1 类（在 E1 中）

### 3.4 过程质量假设

**H7（过程质量假设）**：领域 RAG 不仅提升结论正确率，还提升答案的过程质量（证据忠实度、引用准确率、推理完整性），且过程质量的提升幅度在强模型上更为显著。
- 检验方式：过程指标的知识来源主效应和交互效应
- 通过标准：证据忠实度增益 > 结论正确率增益，强模型上过程增益更明显

## 4. 3×3 析因实验设计

### 4.1 设计概述

本研究采用 **3（模型能力：弱/中/强）× 3（知识来源：无知识/联网搜索/领域 RAG）** 的被试间析因设计。

```
                    模型能力（Ability, A）
           ┌──────────┬──────────┬──────────┐
           │  A1 弱    │  A2 中    │  A3 强    │
        ┌──┼──────────┼──────────┼──────────┤
        │K1│  K1A1    │  K1A2    │  K1A3    │
知识来源  │  │  纯模型   │  纯模型   │  纯模型   │
（Knowledge │  │  基线最低  │          │  天花板    │
  K）   ├──┼──────────┼──────────┼──────────┤
        │K2│  K2A1    │  K2A2    │  K2A3    │
        │  │  + 搜索   │  + 搜索   │  + 搜索   │
        │  │  增益较大  │          │  增益较小  │
        ├──┼──────────┼──────────┼──────────┤
        │K3│  K3A1    │  K3A2    │  K3A3    │
        │  │  + RAG   │  + RAG   │  + RAG   │
        │  │  增益最大  │          │  整体最优  │
        └──┴──────────┴──────────┴──────────┘
```

### 4.2 自变量

#### 自变量 A：模型能力（3 水平）

| 水平 | 代号 | 拟选模型 | 选择依据 |
|------|------|---------|---------|
| 弱 | A1 | Qwen3.5-Flash（或同级别） | 轻量级模型，参数化知识有限，代表低资源场景 |
| 中 | A2 | Qwen3.5-Plus（或同级别） | 中等能力模型，有一定内置知识 |
| 强 | A3 | Qwen3.5-Max（或同级别） | 最强模型，参数化知识最丰富 |

> 具体模型 ID 待实验前最终确认，确保三个模型在同一 API 接口下可用。

#### 自变量 K：知识来源（3 水平）

| 水平 | 代号 | 说明 | 模拟场景 |
|------|------|------|---------|
| 无知识 | K1 | 模型直接回答，不提供任何外部知识 | 纯模型闭卷回答，检验内置知识 |
| 联网搜索 | K2 | 通过搜索 API 获取相关网页结果作为上下文 | 模拟"用搜索引擎查资料"的工作方式 |
| 领域 RAG | K3 | 从环评法规知识库中检索相关标准条文 | 模拟"查专业法规手册"的工作方式 |

**为什么设置 K2？**
K2（联网搜索）是关键的中间水平，用于区分"有知识就行"和"知识需要专业质量"两种机制。如果 K2 与 K3 效果接近，说明知识的"量"比"质"重要；如果 K3 显著优于 K2，说明领域知识的"质"有独有价值。

### 4.3 因变量

主要因变量：**结论正确率**（最终判断 CORRECT/INCORRECT 与金标准一致的比例）

次要因变量：过程指标（见第 6 章评价指标体系）

### 4.4 控制变量

- **提示词格式**：所有条件使用相同的系统提示词模板，仅替换知识上下文部分
- **生成参数**：temperature = 0.1，max_tokens = 4096，统一设置
- **题目顺序**：所有条件下题目顺序一致
- **重复次数**：每个条件独立运行 3 次，取众数结论作为最终答案

### 4.5 统计分析方法

1. **描述性统计**：计算各条件下的正确率均值、标准差、95% 置信区间
2. **双因素 ANOVA**：检验模型能力、知识来源的主效应和交互效应
3. **事后检验**：Tukey HSD 多重比较，确定具体哪些水平间存在显著差异
4. **简单效应分析**：在交互效应显著时，分析各模型水平上的知识来源效应
5. **分层分析**：按 EP 任务类型分层，重复上述分析，检验任务异质性

## 5. E×P 任务分类框架

### 5.1 框架概述

本研究提出一个二维任务分类框架，将环评审核任务按"外部知识依赖度"和"推理复杂度"两个维度分类，用于系统分析 RAG 表现的任务异质性。

```
                    P 维度：推理复杂度
            P0（直接查找）    P1（计算/推理）
         ┌────────────────┬────────────────┐
  E0     │     E0P0       │     E0P1       │
（报告内）│   字段抽取类    │   一致性复算类  │
  E      ├────────────────┼────────────────┤
  维度  E1     │     E1P0       │     E1P1       │
（需外部）│   标准查阅类    │   综合推理类    │
  知识   └────────────────┴────────────────┘
```

### 5.2 E 维度：外部知识依赖度（External Knowledge Dependency）

**定义**：完成该任务所需的核心知识是否存在于给定的环评报告中，还是需要从外部法规标准中获取。

| 类别 | 代号 | 定义 | 典型任务 |
|------|------|------|---------|
| 报告内知识 | E0 | 答案所需的所有信息都在环评报告正文中，不需要引用外部标准 | 从报告中提取数据、核对报告内数据一致性、复算报告内已有的计算 |
| 外部知识 | E1 | 答案需要引用报告以外的法规、标准、导则等外部知识 | 判断排放是否达标、识别危废类别、评价废气收集效率是否合理 |

**理论意义**：E 维度决定了 RAG 增益的理论上限——E0 类题 RAG 理论上没什么用（知识已经在报告里了），E1 类题 RAG 才有发挥空间。

### 5.3 P 维度：推理复杂度（Procedural Complexity）

**定义**：得出答案需要的认知操作深度——是直接的信息匹配/提取，还是需要计算、推理、综合判断。

| 类别 | 代号 | 定义 | 典型任务 |
|------|------|------|---------|
| 直接查找 | P0 | 答案可以直接从文本中找到，或做简单的匹配判断 | 提取某个数据、判断某个标准限值是多少 |
| 计算推理 | P1 | 答案需要经过计算、多步推理、或多信息源综合判断才能得出 | 复算排放量、判断收集效率是否合理、识别危废类别 |

**理论意义**：P 维度决定了 RAG 增益的"转化率"——即使知识有了，能不能用好还要看推理能力。P1 类题上，模型能力的差异会更明显。

### 5.4 四类任务详解

#### E0P0：字段抽取类（报告内 + 直接查找）

**特点**：答案就在报告里，直接找就行。
**典型题目**：
- "该项目的环保投资是多少万元？"
- "项目劳动定员多少人？"
- "废水排放量是多少 t/a？"

**RAG 预期增益**：最小（≈3-5%）。知识已经在报告里了，RAG 帮不上什么忙。主要靠模型的阅读理解和信息提取能力。

**为什么还需要这一类？** 作为"基线中的基线"，检验 E0 类题上 RAG 是否真的没用（验证分类框架的有效性）。

#### E0P1：一致性复算类（报告内 + 计算推理）

**特点**：数据都在报告里，但需要计算、比对、推理才能得出结论。
**典型题目**：
- "报告中生活污水排放量 72t/a 是否正确？（已知 8 人，用水 10m³/人·a，排放系数 0.9）"
- "VOCs 有组织排放量 0.9089t/a + 无组织 0.90867t/a = 1.81757t/a，与总量章节数据是否一致？"
- "纯水制备浓水量 175t/a 的计算是否合理？"

**RAG 预期增益**：较小（≈5-10%）。数据都在报告里，主要靠计算和推理能力。RAG 可能提供计算方法参考但作用有限。

**模型能力差异**：大。P1 类题上强模型的推理优势会很明显。

#### E1P0：标准查阅类（需外部知识 + 直接查找）

**特点**：答案在外部法规标准里，查到就能答对，查不到就答不对。
**典型题目**：
- "该项目 VOCs 排放执行什么标准？排放限值是多少？"
- "废活性炭属于哪类危险废物？废物代码是什么？"
- "厂界噪声执行几类标准？昼间限值是多少？"

**RAG 预期增益**：最大（≈25-35%）。纯模型靠内置知识答不准，RAG 一查就有。

**为什么这是核心题类？** 因为这是"知识替代效应"最直接的检验场——如果强模型在 E1P0 上 RAG 增益仍然很大，说明内置知识覆盖不了，RAG 不可替代。

#### E1P1：综合推理类（需外部知识 + 计算推理）

**特点**：既需要外部知识，又需要推理计算，是最难的一类题。
**典型题目**：
- "注塑工位废气收集效率取 50% 是否合理？（已知：包围式集气罩，控制风速 0.5m/s）"
- "废气设计风量 7000m³/h 是否合理？（已知：集气罩尺寸、控制风速）"
- "以下危废识别是否正确：废机油桶 → HW08，900-249-08"

**RAG 预期增益**：中等（≈20-28%）。知识有帮助，但不是全部——还要会用知识做推理。

**模型能力差异**：也大。强模型不仅知识多，推理也强，双重优势。

### 5.5 分类框架的预期规律

| 规律 | 内容 | 理论依据 |
|------|------|---------|
| **E 维度决定 RAG 增益上限** | E1 类增益 > E0 类增益 | E0 类知识已经在报告里，RAG 没什么可补的 |
| **P 维度决定模型差异幅度** | P1 类模型差异 > P0 类模型差异 | P1 需要推理能力，强模型的推理优势更明显 |
| **增益排序** | E1P0 > E1P1 > E0P1 > E0P0 | 知识依赖度越高、推理越简单，RAG 帮助越大 |

## 6. 评价指标体系

### 6.1 三层指标架构

```
第一层：结论准确率（核心指标）
    ↓
第二层：过程指标（诊断指标，按EP分类差异化）
    ↓
第三层：错误类型分析（深度诊断）
```

### 6.2 第一层：结论准确率

**定义**：模型最终判断（CORRECT / INCORRECT）与金标准一致的题目比例。

**计算方式**：`正确率 = 答对题数 / 总题数 × 100%`

**特点**：
- 客观、无争议
- 是论文的核心结果指标
- 但只能告诉你"对不对"，不能告诉你"为什么对/错"

### 6.3 第二层：过程指标（按 EP 差异化设计）

过程指标用于诊断"对在哪里、错在哪里"，不与结论分兑换。

> **注意**：以下权重为初始权重 v0.1，实验后根据实际数据校准最终权重。过程指标是诊断工具，不是"辛苦分"。

#### E0P0（字段抽取类）过程指标

| 指标 | 初始权重 | 说明 |
|------|---------|------|
| 章节定位准确率 | 30% | 是否找到了正确的章节/位置 |
| 数据提取准确率 | 70% | 提取的数值是否准确 |

#### E1P0（标准查阅类）过程指标

| 指标 | 初始权重 | 说明 |
|------|---------|------|
| 标准引用准确率 | 40% | 引用的标准名称、编号是否正确 |
| 数值准确率 | 60% | 查到的限值/代码等数值是否准确 |

#### E0P1（一致性复算类）过程指标

| 指标 | 初始权重 | 说明 |
|------|---------|------|
| 参数提取准确率 | 25% | 从报告中提取的原始参数是否正确 |
| 公式/方法正确率 | 40% | 使用的计算公式/方法是否正确 |
| 计算结果准确率 | 35% | 最终计算结果是否正确 |

#### E1P1（综合推理类）过程指标

| 指标 | 初始权重 | 说明 |
|------|---------|------|
| 场景识别准确率 | 20% | 是否正确识别了审核场景和适用标准 |
| 知识引用准确率 | 30% | 引用的知识/标准是否正确 |
| 推理完整性 | 25% | 推理链条是否完整、逻辑是否自洽 |
| 最终判断准确率 | 25% | 最终结论是否正确 |

### 6.4 第三层：错误类型分析

#### 按错误方向分

| 错误类型 | 定义 | 通俗说法 |
|---------|------|---------|
| **假阳性（FP）** | 金标准 CORRECT，模型判 INCORRECT | 没毛病但说有毛病，冤枉好人 |
| **假阴性（FN）** | 金标准 INCORRECT，模型判 CORRECT | 有毛病但说没毛病，放纵坏人 |

**衍生指标**：
- 精确率（Precision）= TP / (TP + FP)
- 召回率（Recall）= TP / (TP + FN)
- F1 值 = 2 × 精确率 × 召回率 / (精确率 + 召回率)
- 假阳性率 = FP / (FP + TN)
- 假阴性率 = FN / (FN + TP)

> **环评审核场景判断**：假阴性（漏检错误）比假阳性（过度审核）后果更严重。假阳性仅增加人工复核成本，假阴性可能导致实质性错误未被发现。

#### 按错误环节分

| 错误类型 | 定义 | 对应 EP 类 |
|---------|------|-----------|
| 提取错误 | 数据/信息从源文本中提取错了 | E0 类为主 |
| 计算错误 | 公式用对了但数算错了 | P1 类为主 |
| 知识错误 | 引用的标准/知识本身不对 | E1 类为主 |
| 推理错误 | 知识对了但推理/判断逻辑错了 | P1 类为主 |
| 方法错误 | 用了错误的计算/判断方法 | E1P1 为主 |

#### 幻觉检测

| 幻觉类型 | 定义 | 出现场景 |
|---------|------|---------|
| 编造标准 | 引用了不存在的标准名称或编号 | E1 类，K1 条件下最多 |
| 编造数据 | 报告/标准里没有的数据，模型自己编的 | E0、E1 均可能 |
| 编造章节 | 声称"见报告第X章"但实际没有 | E0 类 |

## 7. 预期结果与创新点

### 7.1 预期的 3×3 正确率矩阵

| | 弱模型 (A1) | 中模型 (A2) | 强模型 (A3) | RAG 增益 (K3-K1) |
|---|---|---|---|---|
| **无知识 (K1)** | 45% | 60% | 70% | — |
| **联网搜索 (K2)** | 60% (+15%) | 69% (+9%) | 75% (+5%) | — |
| **领域 RAG (K3)** | 74% (+29%) | 83% (+23%) | 86% (+16%) | 整体 +22% |

### 7.2 预期的 EP 分层增益（强模型上）

| 题型 | 无知识 (K1) | 领域 RAG (K3) | RAG 增益 |
|------|------------|--------------|---------|
| E0P0 字段抽取 | 85% | 88% | +3% |
| E1P0 标准查阅 | 55% | 88% | **+33%** |
| E0P1 一致性复算 | 65% | 70% | +5% |
| E1P1 综合推理 | 55% | 83% | +28% |

**增益排序验证**：E1P0 (+33%) > E1P1 (+28%) > E0P1 (+5%) > E0P0 (+3%) ✅

### 7.3 三个核心创新点

**I1：知识替代效应的边界发现**
> 首次在中文环评法规密集型场景中系统检验知识替代效应，发现强模型在通用知识上接近饱和，但在地方标准等长尾专业知识上仍存在显著的知识缺口——揭示了法规密集型领域中知识替代的边界，拓展了 RAG scaling 理论的领域特异性。

**I2："弱模型缺量、强模型缺专"的知识质量梯度规律**
> 构建三档知识质量的系统对比框架，揭示知识质量与模型能力的交互规律：弱模型从任何外部知识中都能显著受益（"缺量"），而强模型从领域 RAG 中获得的增益远大于通用搜索（"缺专"）——为 RAG 系统的分层建设策略提供了实证依据。

**I3：E×P 任务分类框架与任务异质性机制**
> 提出"外部知识依赖性 × 推理复杂度"的二维任务分类框架，系统揭示 RAG 表现的任务异质性规律：E 维度决定 RAG 增益的上限，P 维度决定模型能力差异的幅度——为理解 RAG 在不同任务上的效用差异提供了理论分析工具。

### 7.4 创新点的证据链

| 创新点 | 核心证据 | 辅助证据 | 关键数字 |
|--------|---------|---------|---------|
| I1 知识替代边界 | 强模型 E1P0 增益 ≥ 20% | 地方标准题增益 > 国家标准题增益 | +33% |
| I2 弱缺量强缺专 | 弱模型 K2/K3 增益比 > 0.7；强模型 < 0.4 | 过程质量指标的提升模式 | 增益差 11% |
| I3 EP 分类框架 | 增益排序 E1P0 > E1P1 > E0P1 > E0P0 | 错误类型分布的系统迁移 | E0 vs E1 增益差 26.5% |

## 8. 实验设置与实施流程

### 8.1 评价集

- **总题量**：40 题
- **EP 分布**：E0P0 × 10、E1P0 × 10、E0P1 × 10、E1P1 × 10（严格均衡）
- **题目来源**：基于真实环评报告构造，每道题附有金标准答案和核验依据
- **题目格式**：单选题 + 简答题混合，核心判断为 CORRECT / INCORRECT 二元

### 8.2 实验条件

| 维度 | 参数 | 值 |
|------|------|----|
| 模型 A1 | 弱模型 | 待确认（拟 Qwen3.5-Flash） |
| 模型 A2 | 中模型 | 待确认（拟 Qwen3.5-Plus） |
| 模型 A3 | 强模型 | 待确认（拟 Qwen3.5-Max） |
| 生成参数 | temperature | 0.1 |
| 生成参数 | max_tokens | 4096 |
| 重复次数 | 每条件独立运行 | 3 次，取众数 |
| 评分方式 | 自动评分 + 人工抽样核验 | 结论级自动，过程级结构化判定 |

### 8.3 实施流程

```
第 0 步：实验前确认（1 天）
  ├─ 确认三个模型 ID 和 API 可用性
  ├─ 确认 K2 联网搜索实现方案
  ├─ 确认 K3 领域 RAG 知识库配置
  └─ 最终冻结评价集 40 题

第 1 步：冒烟测试（半天）
  ├─ 每个条件跑 2-3 题
  ├─ 验证输出格式和评分逻辑
  └─ 调试 prompt 和参数

第 2 步：主体实验（3-5 天）
  ├─ K1 组：无知识基线（3 个模型 × 40 题 × 3 次）
  ├─ K2 组：联网搜索（3 个模型 × 40 题 × 3 次）
  └─ K3 组：领域 RAG（3 个模型 × 40 题 × 3 次）

第 3 步：可选消融（1-2 天）
  └─ R0 组：空上下文格式对照（至少跑强模型）

第 4 步：评分与分析（2-3 天）
  ├─ 自动评分 + 人工抽样核验
  ├─ 描述统计 + ANOVA + 事后检验
  ├─ EP 分层分析
  └─ 错误类型标注与分析
```

### 8.4 质量控制

1. **金标准质量**：每道题的金标准答案均经过原始报告核验，确保准确无误
2. **评分一致性**：自动评分逻辑经过人工抽样核验，一致率 ≥ 95%
3. **实验可复现**：所有 prompt、参数、模型版本、知识库版本均完整记录
4. **异常值处理**：3 次重复中如果出现不一致，分析原因并记录
