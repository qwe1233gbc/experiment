# GPT 出题任务说明

## 任务

基于提供的 **11 份环评报告片段** 和 **38 个法规标准知识卡**，
生成高质量的**环评审核问答对**（Q&A pairs）。

## 目标

生成的问答对应能够测试：
- 大模型在环评审核场景下的事实核查能力
- 模型能否利用报告内数据 + 外部标准知识进行综合判断
- 不同难度层级的区分度（简单/中等/困难）

## 题目类型

### E0P0：纯报告内事实题（不需要外部知识）
- 例：项目环保投资是多少万元？
- 直接从报告中能找到答案

### E0P1：报告内计算/复算题（不需要外部知识）
- 例：根据报告给出的数据，核算生活污水排放量是否合理
- 答案在报告内，但需要计算或逻辑推导

### E1P0：事实核查题（需要外部知识）
- 例：报告引用的排放标准是否正确？
- 需要结合报告内容 + 外部标准知识判断

### E1P1：计算/推理题（需要外部知识）
- 例：根据设计风量公式，复核报告中的集气罩风量是否满足规范要求
- 需要报告数据 + 外部标准公式/参数 + 计算推理

## 质量要求

1. **题目明确**：问题表述清晰，不产生歧义
2. **有标准答案**：每题都有明确的正确答案（来自报告或标准）
3. **难度分层**：简单、中等、困难各占一定比例
4. **有干扰性**：难题需要有易错点，不是一眼就能看出
5. **真实场景**：题目要符合实际环评审核工作中的真实问题
6. **不含金标泄漏**：题目中不能暗示答案

```json
    }

```

## 出题建议

### 优先出的题目方向（区分度高）

1. **标准适用边界判断** — 某个标准到底适不适用这个项目
2. **危废归类判定** — 废物代码、类别、特性是否正确
3. **设计风量/收集效率复算** — 公式、参数、计算是否正确
4. **排放标准限值核对** — 报告引用的限值是否准确
5. **VOCs 总量替代/总量控制** — 比例、削减量是否符合要求
6. **行业分类判定** — 国民经济行业小类是否匹配
7. **厂区内无组织排放达标** — 监控点浓度是否超标

### 容易出的题（天花板效应，少出）

- 简单的投资比例、面积等数字查找题
- 显而易见的事实陈述题

### 注意事项

- 每题必须能在提供的材料中找到答案依据
- 如果材料不足无法出题，注明缺少什么材料
- 不要出超出提供材料范围的题
- 尽量覆盖不同项目和不同污染因子（水、气、声、固废、危废）

## 期望数量

优先出 **E1P0 和 E1P1 类型的难题**（需要外部知识的），
因为这些题最能区分模型能力。

建议产出：15-20 道高质量题，其中 E1P0 约 8 道，E1P1 约 7 道，E0P0/E0P1 少量作对照。
