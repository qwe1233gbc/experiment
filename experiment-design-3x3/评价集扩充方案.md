## 二、筛选标准

### 2.1 硬性筛选条件（必须全部满足）

| 条件 | 说明 | 数据来源字段 |
|---|---|---|
| **客观可评分** | 答案唯一、明确，不需要主观判断 | `objective_benchmark_suitable = YES` / `gold_deterministic = YES` |
| **分类置信度 HIGH** | EP 分类经过审计，争议小 | `classification_confidence = HIGH` |
| **recommended_action = KEEP** | 不需要重写或拆分，可以直接使用 | `recommended_action = KEEP` |
| **有完整金标准** | 包含标准依据 + 正确结论 + 审核要点 | `gold_final_answer` 非空且完整 |
| **无提示词泄露风险** | 题目本身不包含答案线索 | 人工检查 |

### 2.2 软性筛选条件（优先满足）

| 条件 | 说明 | 优先级 |
|---|---|---|
| **行业/项目多样性** | 尽量覆盖不同行业（塑胶、五金、电子等）和不同标准类型 | 高 |
| **难度梯度** | 每类内部包含简单、中等、较难不同难度的题 | 高 |
| **知识多样性** | E1 类题尽量覆盖不同的标准体系（噪声、固废、大气、水等） | 高 |
| **表述清晰度** | 题目表述清晰、无歧义 | 中 |
| **不与 pilot16 重复** | 避免题目过于相似 | 中 |

### 2.3 排除标准

- 过于简单的纯事实回忆题（如"XX标准的全称是什么"）
- 过于开放、答案不唯一的题
- 需要大量背景知识才能理解题意的题
- 与 pilot16 题目高度相似的题（避免同质性过高）
- 金标准存疑或有争议的题

## 四、质量核验流程

每道新增题目必须经过以下流程，确保金标准质量：

### 第一步：初筛（自动）

从候选池中按以下条件初筛：
1. `objective_benchmark_suitable = YES`（或等效条件）
2. `classification_confidence = HIGH`
3. `recommended_action = KEEP`（或等效）
4. 题目文本长度 > 20 字符（排除不完整题）
5. 金标准答案非空

### 第二步：EP 分类复核（人工，约 30 分钟）

对初筛通过的题目，人工复核 EP 分类是否正确：
- **E 维度**：答案是否需要报告以外的外部知识？
  - E=0：答案完全可以从报告文本中找到/推出
  - E=1：必须查阅外部标准/政策/规范才能作答
- **P 维度**：需要几步推理？
  - P=0：单步判断或直接抽取
  - P=1：需要多步推理、计算或逻辑链

输出：每题标注分类置信度（HIGH/MEDIUM/LOW），仅保留 HIGH。

### 第三步：金标准核验（人工，约 2-3 小时）

对分类复核通过的题目，核验金标准质量：

| 核验项 | 标准 |
|---|---|
| **结论明确** | 金标准有明确的"匹配/不匹配"结论，不含糊 |
| **依据充分** | 结论有明确的标准依据（标准名称 + 编号 + 条款） |
| **数值准确** | 涉及数值计算的，公式和结果正确 |
| **逻辑完整** | 推理过程清晰，从证据到结论的链条完整 |
| **表述规范** | 金标准表述清晰、无歧义 |

每道题标注：
- 金标准质量：A（优秀）/ B（合格）/ C（不合格）
- 不合格原因：结论不明确 / 依据不足 / 数值错误 / 逻辑不清 / 其他

仅保留 A 和 B 级。

### 第四步：多样性平衡（人工，约 30 分钟）

在通过质量核验的题目中，按以下原则选择最终题目：
1. 每类 EP 选 10 题（或尽可能接近）
2. 确保子类型多样性（见 3.2 节）
3. 确保知识领域多样性（噪声、固废、大气、水等）
4. 确保项目/行业多样性
5. 确保难度梯度（简单:中等:较难 ≈ 3:5:2）

### 第五步：格式统一（自动 + 人工，约 1 小时）

将最终入选的题目统一格式，与 pilot16 FROZEN 的字段对齐：

必要字段：
- `question_id`：统一命名规则（如 `DEV_XXX_任务类型`）
- `project_id`：项目编号
- `task_type`：任务类型标签
- `EP_class`：E0P0 / E1P0 / E0P1 / E1P1
- `question`：审核题目
- `report_context`：相关报告片段（上下文）
- `gold_conclusion_type`：金标准结论类型（MATCH/MISMATCH/UNABLE/NA）
- `gold_final_answer`：金标准完整答案
- `gold_evidence_items`：金标准证据条目（外部知识）
- `gold_audit_points`：金标准审核要点
- `gold_procedural_steps`：金标准推理步骤
- `answer_type`：答案类型（数值/分类/文本）
- `source_file`：来源报告
- `classification_confidence`：分类置信度
- `gold_quality`：金标准质量等级

## 五、实施步骤与时间估算

| 步骤 | 内容 | 预计时间 | 负责人 | 产出物 |
|---|---|---|---|---|
| **Step 1** | 从 benchmark 和 new_candidates 中初筛（自动筛选 + 人工快速浏览） | 1 小时 | DSH | 初筛清单（~30-40 题候选） |
| **Step 2** | EP 分类复核 | 30 分钟 | DSH + 用户确认 | 分类确认清单 |
| **Step 3** | 金标准质量核验 | 2-3 小时 | 用户（环评专业背景） | 质量评级清单 |
| **Step 4** | 多样性平衡与最终入选 | 30 分钟 | 共同确认 | 最终入选 40 题清单 |
| **Step 5** | 格式统一，生成最终评价集 Excel | 1 小时 | DSH | `dev_40_questions_FROZEN.xlsx` |
| **Step 6** | RAG 检索结果预生成（为 K3 条件准备） | 1-2 小时 | DSH | `dev_40_rag_snapshot.jsonl` |
| **Step 7** | 抽检 5 题做冒烟测试 | 30 分钟 | DSH | 冒烟测试报告 |

**总预计时间**：6-8 小时（不含等待时间）

## 六、质量验收标准

最终评价集需满足以下标准：

| 验收项 | 标准 |
|---|---|
| **总题数** | 36-40 题 |
| **EP 均衡性** | 每类 9-11 题，偏差不超过 ±1 |
| **金标准质量** | 全部通过人工核验，A 级 ≥ 70%，B 级 ≤ 30%，无 C 级 |
| **分类一致性** | 全部 HIGH 置信度 |
| **知识多样性** | 覆盖 ≥ 4 类标准体系（噪声/固废/大气/水等） |
| **任务多样性** | 每类 EP 内 ≥ 3 种子类型 |
| **格式完整性** | 所有必要字段非空率 100% |
| **可复现性** | 所有题目有明确来源（项目+章节） |

## 七、风险与应对

| 风险 | 概率 | 影响 | 应对措施 |
|---|---|---|---|
| E1P0 高质量题不足 | 中 | E1P0 只能凑到 7-8 题 | 1）降低置信度要求到 MEDIUM；2）从其他来源补充；3）实在不够就接受 8 题，其他类适当增加 |
| E0P0 子类型单一 | 高 | 全是"环保投资占比"，多样性不足 | 1）从 benchmark 或其他来源补充不同类型；2）如果不够，人工构造 2-3 道新题（从报告中抽取字段） |
| 金标准质量不达标 | 中 | 大量题目需要返工 | 初筛时严格把关，优先选 benchmark 中 KEEP 且 HIGH 的题 |
| 报告上下文缺失 | 中 | 有些题没有对应的报告片段 | 从原始报告中提取上下文，或标注为"需要报告全文" |
