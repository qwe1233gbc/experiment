# 危险废物识别证据门槛（2026-08-12）

1. 先按审核时点适用的GB 34330判断物质是否属于固体废物：GB 34330—2017适用于2026-02-28及以前，GB 34330—2025自2026-03-01起适用。
2. 再按审核时点适用名录匹配来源行业、产生工序、废物描述与代码：2021年版适用于2024-12-31及以前，2025年版自2025-01-01起适用。
3. 未列入名录但可能具有危险特性时，依GB 5085.1—6、GB 5085.7—2019和HJ 298—2019开展鉴别；名称相似或同类项目经验不能替代鉴别。
4. 只有报告自报代码而缺少工序、成分或名录条目映射时，不得确认代码，输出 `basis_status=insufficient`。
5. 报告时点与审核时点版本不同，要分别给出“历史合规性”和“当前整改建议”，禁止用新版本倒推历史错误。
